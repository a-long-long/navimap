## 等高线 SRTM「自动下载 DEM」链路接通（#88 遗留 WIP）

`44899a8` 等高线渲染落地但" SRTM 下载链路待接"。本日补齐：

- 新增 `tools/download_srtm.py`（**仅 Python 标准库 urllib+gzip，零第三方依赖**）：
  给定 `--bbox` 算出覆盖的 1° 瓦片 `N37E114`，从 `--mirror` 下载
  `<mirror>/N37/N37E114.hgt.gz` 并就地 gunzip 为 `.hgt`。默认镜像 AWS skadi
  （`https://s3.amazonaws.com/elevation-tiles-prod/skadi`，自动回退 alt 主机）；
  单瓦片失败不致命（海洋/无数据/被墙都降级），支持 `--keep-gz` / `--mirror`。
- `tools/gen_contours.c` 增加 `--download[=MIRROR]` 与 `--downloader=PATH`：
  加载瓦片前调 `python3 download_srtm.py` 预取缺失瓦片；脚本找不到/下载失败
  **降级为现有"跳过缺失瓦片"行为，不致命**。不带 `--download` 时行为完全不变
  （仍是零链接期外部依赖）。脚本路径探测顺序：`--downloader` > `$GEN_CONTOURS_PY`
  > `argv0/../tools/` > `tools/`（cwd）> `$NAVIMAP_ROOT/tools/`。
- 离线 `file://` 伪镜像端到端验证通过：瓦片命名/URL 构造/gunzip 全对；
  `gen_contours --download` 实跑拉到 1 张瓦片并产出 contours/polyrefs/pts 三件套（rc=0）。

### 用法
```
python3 tools/download_srtm.py --bbox=39.4,115.4,41.1,117.5 --out=/tmp/srtm \
    [--mirror=URL]
# 或一步到位（生成等高线 + 自动拉 DEM）：
gen_contours --out-dir=products/graph/beijing --hgt-dir=/tmp/srtm \
    --bbox=39.4,115.4,41.1,117.5 --download
```

### 跨平台注意事项
- Windows 副机（MSYS2）跑 `gen_contours --download` 需 `python3` 在 **Windows PATH**
  （不是仅 MSYS2 PATH）；否则 system() 调 cmd.exe 找不到 python3 → 自动降级跳过下载。
- 中国大陆直连 AWS S3 不稳，可用 `--mirror` 指向可达镜像/代理。
- regress 门禁仍 76/3（gen_contours 不在受测用例里；本改动为纯增量，未引入回归）。

## PBF 下载"先查本地、有更新才询问"（`download_dialog.cpp`）

用户审计结论：SRTM（download_srtm.py）已有"先查本地、缺失才下载"，但 PBF 下载
（`DownloadDialog::startDownload`）原本无条件下载覆盖。用户定调"存在即跳过下载"，
后追加"存在时比对远端新鲜度、有更新才弹窗询问"。改动：

- `startDownload()`：本地 pbf 已存在且非空 → 发 `m_nam->head()` 比对远端；
  不存在则直接 `beginDownload()`。
- 抽出 `beginDownload()`：承载原先真正发起下载的逻辑（get + 进度/落盘连接），
  被"不存在"和"用户确认更新"两条路径共用。
- 新增 `onHeadFinished()`：HEAD 回包比对 `Last-Modified` / `Content-Length` 判远端是否更新；
  - 比对失败（无网络/不可达）→ 稳妥跳过（不覆盖本地）；
  - 无更新 → 跳过；
  - 有更新 → `QMessageBox::question` 询问"是否下载更新"，选否则保留本地。
- 重定向策略用 `#if QT_VERSION >= 5.15.0` 守卫（本机 Qt5.11.3 无该枚举，副机 Qt6 默认跟随）。
- `QDateTime::fromString(..., Qt::RFC2822Date)` 解析 Last-Modified；`onMapsDownloaded` 不触发
  （跳过下载时不弹"下载完成"，避免误导）。
- 增量编译 navmap_qt 零警告（BUILD_EXIT=0）。

   "距河南 152km"并建议下河南。加省会坐标表后变成"大致在重庆（按最近省会推断）"。
   ⇒ **`nearest_km` 与 `nearest_loaded_km` 必须是两个字段**，用途不同。
2. ★★★ **国别不能光凭"最近省在中国"就断言**：顺带把蒙古乌兰巴托（距河北 bbox 764km）
   报成"中国境内"。改法：只有"离已加载省 ≤ `COV_INLAND_KM`(150km)"才敢说中国境内，
   否则文案写"可能在境外"。阈值宁可保守——没有国界数据时的唯一可辩护做法。
3. ★★ **bbox-only 时建议下载已加载的省**：渤海湾（河北 bbox 内、水域无路）输出
   "建议下载：河北"，而河北明明已加载。⇒ `COV_BBOX_ONLY` 必须单独分支，说"数据已加载、
   此处确实没有路网"，不能复用 `COV_NONE` 的下载建议。
4. ★★ **`%s%s%s` 定长模板拼地名会留空格**：输出过"中国 河北 。"这种带空格句号。
   改成"逐段追加 + 空段跳过 + ` · ` 分隔"。
