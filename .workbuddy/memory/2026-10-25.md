## 坐标系参数修订：西安80 从"仅换椭球"改成有出处的全国 3 参数（J 先生问"公开资料没有吗"）

     全国统一 3 参数 **(−104.57, −45.94, +5.30)**；公式 `[XYZ]84=[XYZ]80+Δ`

     平均经向 8.20 m / 纬向 4.21 m，最大 14.73 / 9.23 m。

### 本轮五个新教训（已进 MEMORY.md）

1. ★★★ **编译期 PATH 放 Qt bin ⇒ gcc 静默死**：`/d/Qt/6.11.2/mingw_64/bin` 里有另一套
   MinGW 运行期 DLL（libstdc++-6 等，版本对应 Qt 自带旧 gcc）。排在 ucrt64 前时
   cc1plus 加载到不匹配的 libstdc++ ⇒ 退出码 1、**stderr 全空**，连 `int main(){}`
   都编不过。分辨特征：**C 文件能编过、C++ 全灭**（cc1 不需要 libstdc++，cc1plus 需要）。
   诊断法：`try()` 矩阵实测各组 PATH；Defender 日志无检出记录 ⇒ 排除 Defender。
   修：`build_win.sh` 的 CLEAN_PATH 与 `cc_retry.sh` 的 MSYS_PATH 都去掉 Qt bin；
   Qt bin 只在**运行期**加（regress.sh `qt_run()`）。
2. ★★ **checkable 按钮的 `toggled` 会递归**：`m_trackBtn` 的 toggled 连回
   `toggleTrackPanel()`，内部再 `setChecked()` ⇒ 再发 toggled ⇒ 无限递归，每层
   refreshTrackPanel 建/删控件 ⇒ 栈耗尽 ⇒ **在 `RtlAllocateHeap` 里 SIGSEGV**
   （与 Defender 杀进程/堆损坏表现一模一样）。修：`QSignalBlocker`。
   定位法：写两个最小复现（QLabel / 面板+菜单栏+Dock+样式表）**都不崩** ⇒ 排除框架，
   回头插桩才看到 "refresh done/visible" 重复上千次。
   ⚠️ 顺带删掉了一条**错误结论**注释（"QListWidget 在 offscreen 下崩"）——错归因比没归因更糟。
3. ★ **`isVisible()` 对未 show 的子控件恒 false** ⇒ 浮层贴位用 `!isHidden()`
   （`--shot-track` 时序正是"先开面板后 show"）。负向对照：改回 isVisible ⇒
   `ASSERT-FAIL 轨迹面板没贴到右栏左边（pos=0,0 340x190 画布 1280x779 右栏 1146）`、RC=1。
4. ★ **面板定位判据不能与窗口尺寸耦合**：`pp.x() > 画布宽/2` 在 `--w=900` 下假红

5. 导入幂等：库里轨迹按 name 替换、收藏按 (name,lat,lon) 查重（`gpx_db_find_fav`），

## 【追加】浮层透明度改向：只淡底板、文字保持清晰

J 先生看完第一版（浮层整体 75% 半透明，"底板+描边+图标+文字"整块一起淡）后
**直接否决**，要求改成「**只淡底板、文字保持清晰**」。这是本轮的全部改动。

### 语义规则（最终）

- 底板 / 描边（`rfill`/`rstroke`/`nfill`/`nrect`）：按 pct **线性缩放 alpha**。
- 前景（`rtext`/`rline`/`rpoint`/`ntext`/`nline`）：**不参与线性淡出** ——
  pct=0 ⇒ 整个浮层隐藏（前景也不画，否则文字孤零零浮在底图上）；pct>0 ⇒ 完全不透明。
- C 侧：`chrome.c` 加 `afg()`（`ak()` 保留给底板）；`navdraw.c` 加 `fg()`（`am()` 给底板）。
- Qt 侧：**弃用 `QGraphicsOpacityEffect`**（它会把文字和图标一起淡掉，与需求冲突）：
  ① `IconButton` 自绘底板时 `bg.setAlpha(qRound(bg.alpha()*k))`，图标/文字的 pen 不乘 k，
  `m_ovlPct<=0` 直接不画；② 面板/输入框用 QSS `rgba(r,g,b,fgA)`；③ `QScrollArea` 必须
  `viewport()->setAttribute(Qt::WA_TranslucentBackground,true)`，否则中间压一块实心；
  ④ 轨迹面板 0% 时不能真隐藏逻辑状态 ⇒ 新增 `m_trackPanelOpen` 记"逻辑上开没开"。
- ★ `qobject_cast<IconButton*>` **编译失败**（`IconButton` 无 `Q_OBJECT` 宏 ⇒
  `static_assert`）⇒ 自绘 QWidget 子类一律用 `dynamic_cast`。

### 判据（`scripts/ovl_px.py` 重写）

- 底板：矩形内**所有变化像素**的 `|M−H|/|O−H|` **中位数** == pct/100（不能取单点，
  底板像素占多数，单点容易采到文字上）。实测：标题栏 0.7581 / C 右栏 0.7347 /
  Qt 右栏 0.7500 / Qt 搜索 0.7500。
- 前景 **口径 a**（主）：`M == O 且 O != H` 逐像素完全相同。
- 前景 **口径 b**（仅当传 `--fgrect`）：`|e75|/|e100| > (1+pct/100)/2`（e = 像素与 0% 底图之差）。
- 保留"矩形外零影响"。

### 踩的坑（5 个）

1. ★★★ **"比值 ≈ 1" 认前景会造假阳性**：浮层未覆盖的边角像素（多出的地图行）恰好凑出
   ≈1 的比值 —— 标题栏矩形里凑出 **424 个假前景** ⇒ 负向对照③（注入"前景也淡"）
   竟然通过 ⇒ 改成"逐像素完全相同"。
2. ★★ **中文 14px 抗锯齿没有 coverage=1 的纯色核** ⇒ "逐像素相同"对文字数不到
   （Qt 搜索按钮「搜索」只数到 **3** 个，图标贡献 49）⇒ 文字改用口径 b。
3. ★★ **口径 b 必须框准前景区才有判别力**：不框时底板边缘给 129 个纯噪声
   （注入前后 129 vs 130，零判别力）；框准文字区后 **111 vs 39**。
   ⇒ 口径 b **只在指定 `--fgrect` 时启用**；C 右栏用口径 a（正向 92 / 注入 0，判别力 100%）。
4. ★ **改 `.hpp` 后 ninja 不自动重编** ⇒ 注入的 bug 没进 exe ⇒ 负向对照④**假通过**。
   修法：`touch src/ui_qt/main_window.cpp` 后重编。
5. ★ **Qt 搜索按钮 rect 给错**：初用 `10,35,70,36` 报"矩形外 406 个像素跟着变" ⇒
