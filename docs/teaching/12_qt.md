# 第 12 课：Qt 前端与边界

> 模块：`src/ui_qt/{qt_main,map_canvas,main_window,download_dialog,qt_icons,qt_font}.{cpp,h}`、`qt_icon_button.hpp`
> 前置：第 8 课 `app_render_to_buf`、第 11 课 `app_nav_sim_tick`/`RouteResult`、Qt Widgets 基础。

## 一、教学目的

理解"遗留 C 系统如何渐进式 Qt 化"——**核心一行不动，只换缓冲归属与叠加层**。学完后学生应能：

- 说明 Qt 前端改了什么、C 核心为什么完全没动：`MapCanvas` 自持一块 `uint32_t` 缓冲、渲染时调第 8 课唯一的 `app_render_to_buf`，再把缓冲包成 `QImage`；C 侧零 SDL 依赖；
- 解释 `QImage::Format_RGB32` 的坑（RGBA8888→黑屏、RGBX8888→红蓝互换），以及"浮层只淡底板、文字保持清晰"的语义（`IconButton` 用 `QSignalBlocker` 避免 checkable 递归、自绘底板按系数算 alpha）；
- 说明 `qt_ui=2` 时 `paint_frame`（第 8 课）跳过 C 侧 chrome/搜索框/面板，由 Qt 真控件承担，但地图渲染、结果图钉、夜间蒙版保留；
- 解释**字体符号不可用**（`inFont()` 全 false）⇒ 图标必须自绘矢量路径（`qt_icons.cpp`），以及把 C 侧 CJK 字体注册进 Qt（`qt_font.cpp`）的原因。

**Qt 混合前端边界原则**

- **C 渲染核心一行不动**：`map_canvas.cpp` 自持一块 `uint32_t` 像素缓冲，渲染时调用第 8 课的唯一入口 `app_render_to_buf`，再把缓冲包成 `QImage` 贴到 `QWidget` 上；叠加层（比例尺/指北针/坐标网/坐标框/路线信息）只用 `QPainter` 在 `paintEvent` 画，不污染 C 渲染核心。
- **Qt 前端不链 SDL**：`m_px` 自 `malloc`（Qt 里是 `new uint32_t[]`），窗口/事件全 Qt；`app_init` 时设 `a.qt_ui = 1` 让 `paint_frame` 跳过自绘 chrome。
- **两套字体互不相干**：地图文字由 C 侧 `stb_truetype`（`render/font.c`）画；Qt 控件文字由 Qt 字体系统画。`qt_font.cpp` 把 C 侧自带字体注册进 Qt，避免控件中文变方块。

## 三、完整实现代码

### 3.1 入口 `src/ui_qt/qt_main.cpp`：`main`（完整）

```cpp
int main(int argc, char **argv)
{
    const char *graph = "products/graph/beijing";
    int w = 1280, h = 800;
    const char *font = NULL;          /* NULL = 默认字体候选链 */
    int font_size = 0;
    const char *q = NULL;             /* 启动时搜一次并跳到第一条结果 */
    const char *pbf_display = NULL;
    int pbf_lru = 3;
    const char *shot = NULL;          /* --shot=path：出一张图就退出 */
    int grid = 0;                     /* --grid：开局打开坐标网叠加层 */
    int grid_subdiv = 0;               /* --grid-subdiv：开局开启网格细分刻度线 */
    int ui_test = 0;                  /* --ui-test：跑无头 UI 自检后退出 */
    int shot_search = 0;              /* --shot-search：截图前先展开搜索框 */
    int shot_track = 0;               /* --shot-track：截图前先展开轨迹面板 */
    int shot_nomap = 0;               /* --shot-nomap：截图前跑无图区弹窗+预选下载自检 */
    int shot_offscreen = 0;           /* --shot-offscreen：离屏像素审计，在 C 核心
                                         缓冲上跑共享审计后退出 */
    const char *datum = NULL;         /* --datum=wgs84|cgcs2000|bj54|xa80：坐标系（命令行优先） */
    const char *datum_grid = NULL;    /* --datum-grid=<file>：图幅改正量格网（入口②） */
    const char *gpx_in[8] = {0};      /* --gpx=<file>：启动即导入（可多次，最多 8 个） */
    int n_gpx_in = 0;
    const char *gpx_out = NULL;       /* --export-gpx=<file>：退出时导出全部轨迹+收藏 */
    /* --ovl-alpha=<key>=<pct>：逐浮层透明度，给无人值守截图做像素判据用。
     * key 见 ui/overlay.h（alpha_search 等）。 */
    struct { NmOverlay id; int pct; } ovl_set[OVL_COUNT] = {{OVL_TITLE,0}};
    int n_ovl = 0;

    /* 以下 flag 供 --shot-offscreen（offscreen_shot_main）使用 */
    double lat = 0, lon = 0, zoom = 12.0;
    int have_center = 0;                 /* 1=给了 --lat/--lon，2=给了 --zoom，3=都给 */
    const char *from_s = NULL, *to_s = NULL;
    int fit_route = 0;
    int open_menu = 0, open_tf = 0, settings_ovl = 0;
    const char *dmap_demo = NULL; int dmap_demo_pct = 0;

    AutoBuildOpt ab;
    memset(&ab, 0, sizeof(ab));
    ab.enable = 1;

    for (int i = 1; i < argc; i++) {
        if (strncmp(argv[i], "--graph=", 8) == 0) graph = argv[i] + 8;
        else if (strncmp(argv[i], "--w=", 4) == 0) w = atoi(argv[i] + 4);
        else if (strncmp(argv[i], "--h=", 4) == 0) h = atoi(argv[i] + 4);
        else if (strncmp(argv[i], "--font=", 7) == 0) font = argv[i] + 7;
        else if (strncmp(argv[i], "--font-size=", 12) == 0)
            font_size = atoi(argv[i] + 12);
        else if (strncmp(argv[i], "--q=", 4) == 0) q = argv[i] + 4;
        else if (strcmp(argv[i], "--no-autobuild") == 0) ab.enable = 0;
        else if (strncmp(argv[i], "--sources=", 10) == 0) ab.src_dir = argv[i] + 10;
        else if (strncmp(argv[i], "--shot=", 7) == 0) shot = argv[i] + 7;
        else if (strcmp(argv[i], "--grid") == 0) grid = 1;
        else if (strcmp(argv[i], "--grid-subdiv") == 0) grid_subdiv = 1;
        else if (strncmp(argv[i], "--datum=", 8) == 0) datum = argv[i] + 8;
        else if (strncmp(argv[i], "--datum-grid=", 13) == 0) datum_grid = argv[i] + 13;
        else if (strncmp(argv[i], "--gpx=", 6) == 0) {
            if (n_gpx_in < (int)(sizeof(gpx_in) / sizeof(gpx_in[0])))
                gpx_in[n_gpx_in++] = argv[i] + 6;
            else fprintf(stderr, "提示: --gpx 最多 %d 个，忽略 %s\n",
                         (int)(sizeof(gpx_in) / sizeof(gpx_in[0])), argv[i] + 6);
        }
        else if (strncmp(argv[i], "--export-gpx=", 13) == 0) gpx_out = argv[i] + 13;
        else if (strncmp(argv[i], "--ovl-alpha=", 12) == 0) {
            if (n_ovl >= (int)(sizeof(ovl_set) / sizeof(ovl_set[0]))) {
                fprintf(stderr, "提示: --ovl-alpha 最多 %d 个\n",
                        (int)(sizeof(ovl_set) / sizeof(ovl_set[0])));
            } else {
                char spec[256];
                snprintf(spec, sizeof(spec), "%s", argv[i] + 12);
                char *eq = strchr(spec, '=');
                if (!eq) { fprintf(stderr, "--ovl-alpha 格式: --ovl-alpha=<key>=<pct>\n"); return 2; }
                *eq = '\0';
                int id = ovl_by_key(spec);
                if (id < 0) { fprintf(stderr, "未知浮层 %s\n", spec); return 2; }
                ovl_set[n_ovl].id = (NmOverlay)id;
                ovl_set[n_ovl].pct = atoi(eq + 1);
                n_ovl++;
            }
        }
        else if (strcmp(argv[i], "--ui-test") == 0) ui_test = 1;
        else if (strcmp(argv[i], "--shot-search") == 0) shot_search = 1;
        else if (strcmp(argv[i], "--shot-track") == 0) shot_track = 1;
        else if (strcmp(argv[i], "--shot-nomap") == 0) shot_nomap = 1;
        else if (strcmp(argv[i], "--shot-offscreen") == 0) shot_offscreen = 1;
        else if (strncmp(argv[i], "--pbf-display=", 14) == 0) {
            pbf_display = argv[i] + 14;
            const char *colon = strrchr(pbf_display, ':');
            if (colon && colon[1] >= '0' && colon[1] <= '9') {
                pbf_lru = atoi(colon + 1);
                size_t dlen = (size_t)(colon - pbf_display);
                static char dirbuf[4096];
                if (dlen < sizeof(dirbuf)) {
                    memcpy(dirbuf, pbf_display, dlen);
                    dirbuf[dlen] = '\0';
                    pbf_display = dirbuf;
                }
            }
        }
        else if (strncmp(argv[i], "--lat=", 6) == 0)  { lat = atof(argv[i] + 6); have_center |= 1; }
        else if (strncmp(argv[i], "--lon=", 6) == 0)  { lon = atof(argv[i] + 6); have_center |= 2; }
        else if (strncmp(argv[i], "--zoom=", 7) == 0) { zoom = atof(argv[i] + 7); }
        else if (strncmp(argv[i], "--from=", 7) == 0) from_s = argv[i] + 7;
        else if (strncmp(argv[i], "--to=", 5) == 0)   to_s = argv[i] + 5;
        else if (strcmp(argv[i], "--fit-route") == 0) fit_route = 1;
        else if (strcmp(argv[i], "--menu") == 0) open_menu = 1;
        else if (strcmp(argv[i], "--panel=tf") == 0) open_tf = 1;
        else if (strcmp(argv[i], "--settings-ovl") == 0) settings_ovl = 1;
        else if (strncmp(argv[i], "--dmap-demo=", 12) == 0) {
            dmap_demo = argv[i] + 12;
            const char *colon = strrchr(dmap_demo, ':');
            if (colon && colon[1] >= '0' && colon[1] <= '9') {
                dmap_demo_pct = atoi(colon + 1);
                size_t n = (size_t)(colon - dmap_demo);
                static char dbuf[128];
                if (n < sizeof(dbuf)) { memcpy(dbuf, dmap_demo, n); dbuf[n] = '\0'; dmap_demo = dbuf; }
            }
        }
        /* 以下 flag 仅 --shot-offscreen（offscreen_shot_main）使用：这里忽略，
           原样转发给 offscreen_shot_main 解析。 */
        else if (strncmp(argv[i], "--out=", 6) == 0) { /* 交给 offscreen_shot_main */ }
        else if (strncmp(argv[i], "--max-class=", 12) == 0) { /* 同上 */ }
        else if (strncmp(argv[i], "--resize-font=", 14) == 0) { /* 同上 */ }
        else if (strncmp(argv[i], "--route=", 8) == 0) { /* 同上 */ }
        else if (strcmp(argv[i], "--sim") == 0) { /* 同上 */ }
        else if (strncmp(argv[i], "--sim-sec=", 11) == 0) { /* 同上 */ }
        else if (strncmp(argv[i], "--sim-deviate=", 14) == 0) { /* 同上 */ }
        else { fprintf(stderr, "未知参数 %s\n", argv[i]); return 2; }
    }

    /* ★ 离屏像素审计通道：--shot-offscreen 在**任何 Qt 初始化之前**就走
     *   共享的 offscreen_shot_main（纯 C、零 SDL、不需要显示环境）。 */
    if (shot_offscreen) {
        return offscreen_shot_main(argc, argv);
    }

    QApplication app(argc, argv);
    app.setApplicationName(QStringLiteral("NavMap"));

    /* ★ Qt 控件的中文字体：Qt 自己画控件文字，走 Qt 的字体系统；地图上的文字
     *   是 C 侧 stb_truetype 画的（两套互不相干）。 */
    qt_setup_fonts(font_size > 0 ? font_size : 0);

    /* ★ Qt 前端**不初始化也不链接 SDL**…… 历史坑（SDL GUI 壳已于 #88 删除）。 */

    /* ★ 双击 exe 时工作目录 = exe 所在目录，默认相对路径解析不到 ⇒ 回退解析。 */
    static char g_graph_buf[4096];
    const char *resolved = graph;
    {
        QString chosen;
        if (is_graph_dir(graph)) {
            chosen = QString::fromUtf8(graph);
        } else {
            QString exeDir = QCoreApplication::applicationDirPath();
            QStringList cands;
            cands << QDir::currentPath() + "/products/graph/beijing";
            for (int k = 0; k <= 3; k++) {
                QString base = exeDir;
                for (int u = 0; u < k; u++) base += "/..";
                cands << base + "/products/graph/beijing";
                QDir gd(base + "/products/graph");
                if (gd.exists()) {
                    for (QString pv : gd.entryList(QDir::Dirs | QDir::NoDotAndDotDot))
                        if (is_graph_dir(gd.filePath(pv).toUtf8().constData()))
                            cands << gd.filePath(pv);
                }
            }
            if (const char *env = getenv("NAVMAP_GRAPH"))
                cands << QString::fromLocal8Bit(env);
            for (const QString &c : cands)
                if (is_graph_dir(c.toUtf8().constData())) { chosen = c; break; }
        }
        if (chosen.isEmpty()) {
            QFileDialog dlg(nullptr,
                QStringLiteral("选择地图目录（含 nodes.bin 的省目录，或其父级的图集根）"),
                QString(), QString());
            dlg.setFileMode(QFileDialog::Directory);
            dlg.setOption(QFileDialog::ShowDirsOnly, true);
            if (dlg.exec() == QDialog::Accepted) {
                QString sel = dlg.selectedFiles().value(0);
                if (is_graph_dir(sel.toUtf8().constData())) chosen = sel;
            }
        }
        if (chosen.isEmpty()) {
            QMessageBox::critical(nullptr, QStringLiteral("NavMap"),
                QStringLiteral("未找到地图数据。请用 start.bat 启动，或在命令行加 --graph=<地图目录>。"));
            return 1;
        }
        QByteArray ba = chosen.toUtf8();
        if ((size_t)ba.size() + 1 < sizeof(g_graph_buf)) {
            memcpy(g_graph_buf, ba.constData(), (size_t)ba.size() + 1);
            resolved = g_graph_buf;
        }
        fprintf(stderr, "[qt-main] 地图目录: %s\n", resolved);
    }

    /* C 核心生命周期：app_init 装图集/字体/搜索库；qt_ui=1 让 paint_frame
     * 跳过自绘 chrome（由 Qt 控件承担）。 */
    App a;
    if (app_init(&a, resolved, w, h, font, font_size, &ab) != 0) {
        QMessageBox::critical(nullptr, QStringLiteral("NavMap"),
            QString::fromUtf8(resolved) +
            QStringLiteral("\n地图加载失败，请检查路径与数据完整性（需含 nodes.bin 或省子目录）。"));
        return 1;
    }
    a.qt_ui = 1;
    for (int i = 0; i < n_ovl; i++)
        app_ovl_alpha_set(&a, ovl_set[i].id, ovl_set[i].pct);

    if (datum) {
        int did = DATUM_WGS84;
        if (!strcmp(datum, "cgcs2000") || !strcmp(datum, "cgcs2000+") ||
            !strcmp(datum, "2000"))
            did = DATUM_CGCS2000;
        else if (!strcmp(datum, "bj54") || !strcmp(datum, "beijing1954") ||
                 !strcmp(datum, "北京54") || !strcmp(datum, "北京1954"))
            did = DATUM_BJ54;
        else if (!strcmp(datum, "xa80") || !strcmp(datum, "xian1980") ||
                 !strcmp(datum, "西安80") || !strcmp(datum, "西安1980"))
            did = DATUM_XA80;
        a.datum = did;
    }

    if (datum_grid) {
        int rc = datum_grid_load((DatumId)a.datum, datum_grid);
        if (rc != 0) {
            fprintf(stderr, "提示: 改正量格网加载失败（%s，错误码 %d），按无格网继续\n",
                    datum_grid, rc);
        } else {
            fprintf(stderr, "已挂改正量格网: %s -> %s\n", datum_grid, datum_short((DatumId)a.datum));
        }
    }

    if (pbf_display) {
        if (mapset_enable_pbf_display(&a.ms, pbf_display, pbf_lru) != 0) {
            fprintf(stderr, "提示: PBF 显示层不可用（目录 %s），改用 nmbin 产物\n",
                    pbf_display);
        } else {
            printf("显示层: 从 PBF 运行时解码（%s，LRU %d 省）\n", pbf_display,
                   pbf_lru);
        }
    }
    for (int i = 0; i < n_gpx_in; i++) {
        int n = app_gpx_import(&a, gpx_in[i]);
        if (n < 0)
            fprintf(stderr, "提示: GPX %s 导入失败（%d）\n", gpx_in[i], n);
        else
            printf("GPX: %s -> %d 条轨迹（含 wpt 转收藏）\n", gpx_in[i], n);
    }
    if (gpx_out) {
        if (app_gpx_export(&a, gpx_out) == 0)
            printf("GPX: 已导出全部轨迹/收藏 -> %s\n", gpx_out);
        else
            fprintf(stderr, "提示: GPX 导出失败（%s）\n", gpx_out);
    }
    if (q) {
        int n = app_search_query(&a, q);
        printf("搜索「%s」%d 条（%llu ms）\n", q, n,
               (unsigned long long)a.su.elapsed_ms);
        if (n > 0) {
            a.view.lat = a.su.hits[0].lat;
            a.view.lon = a.su.hits[0].lon;
            if (a.view.zoom < 14.0) a.view.zoom = 15.0;
        }
    }

    uint64_t tn, te;
    mapset_totals(&a.ms, &tn, &te);
    printf("图: %s  %d 省  节点 %llu  边 %llu\n", graph, a.ms.n,
           (unsigned long long)tn, (unsigned long long)te);
    printf("字体: %s  %d pt\n",
           a.font_used[0] ? a.font_used : "(无)", a.font_size);

    if (have_center & 1) a.view.lat = lat;
    if (have_center & 2) a.view.lon = lon;
    if (zoom > 0)        a.view.zoom = zoom;
    a.view.w = w; a.view.h = h;
    if (settings_ovl) { a.settings_open = 1; a.settings_ovl = 1; }
    if (open_tf)      a.tf_open = 1;
    if (open_menu)    a.menu_open = 1;
    if (grid_subdiv) a.grid_subdiv = 1;
    if (dmap_demo) {
        int prov = -1;
        for (int i = 0; i < a.ms.n; i++)
            if (strcmp(a.ms.srcs[i].name, dmap_demo) == 0) { prov = i; break; }
        if (prov < 0) fprintf(stderr, "提示: 找不到省份 %s 供 --dmap-demo\n", dmap_demo);
        else {
            MapSrc *s = &a.ms.srcs[prov];
            s->pbf_display_mode = 1; s->loaded = 1; s->has_features = 0;
            s->dmap_inflight = 1; s->dmap_progress = dmap_demo_pct;
            a.view.lat = ((double)s->bbox[0] + s->bbox[2]) / 2e7;
            a.view.lon = ((double)s->bbox[1] + s->bbox[3]) / 2e7;
            a.view.zoom = 8;
            int32_t eb[4] = { s->bbox[0], s->bbox[1], s->bbox[2], s->bbox[3] };
            mapset_set_view(&a.ms, eb);
        }
    }
    if (from_s || to_s) {
        if (!from_s || !to_s) { printf("ASSERT-FAIL --from 与 --to 必须成对给\n"); return 1; }
        double alat, alon, blat, blon;
        if (parse_ll(from_s, &alat, &alon) != 0 || parse_ll(to_s, &blat, &blon) != 0) {
            printf("ASSERT-FAIL 起终点格式应为 lat,lon\n"); return 1;
        }
        if (app_nav_plan_sync(&a, alat, alon, blat, blon) != 0) {
            printf("ASSERT-FAIL 算路失败：%s\n", a.nav_msg[0] ? a.nav_msg : "(未知)");
            return 1;
        }
        if (have_center != 3 || fit_route) app_nav_fit(&a);
    }

    fflush(stdout);
    MainWindow win(&a);
    fflush(stdout);

    if (ui_test) {
        win.resize(w, h);
        win.show();
        QApplication::processEvents();
        int rc = win.runUiSelfTest();
        app_shutdown(&a);
        return rc;
    }

    if (shot) {
        int shot_fail = 0;
        if (grid) win.setShowGrid(true);
        if (shot_search) win.expandSearchForShot();
        if (shot_track) win.openTrackPanelForShot();
        if (shot_nomap) {
            for (int i = 0; i < 3; i++) QApplication::processEvents();
            shot_fail |= win.runNoMapPromptForShot();
        }
        win.resize(w, h);
        win.show();
        QApplication::processEvents();
        for (int i = 0; i < 3; i++) QApplication::processEvents();
        if (shot_track) {
            const QSize cs = win.canvasSize();
            const QPoint pp = win.trackPanelPos();
            const QSize ps = win.trackPanelSize();
            const QPoint rp = win.rightOverlayPos();
            if (!win.trackPanelVisible() || ps.width() <= 0 ||
                cs.width() <= 0 || pp.x() <= cs.width() / 2 ||
                pp.x() + ps.width() > rp.x() + 1) {
```

```cpp
void MapCanvas::ensureBuffer(int w, int h)
{
    if (m_px && m_px_w == w && m_px_h == h) return;
    delete[] m_px;
    m_px = new uint32_t[(size_t)w * (size_t)h]();
    m_px_w = w;
    m_px_h = h;

void MapCanvas::renderNow()
{
    int w = m_a->view.w > 0 ? m_a->view.w : width();
    int h = m_a->view.h > 0 ? m_a->view.h : height();

                          &m_st) == 0) {

void MapCanvas::drawScaleBar(QPainter &p)
{
    double mpp = (40075016.686 * cos(m_a->view.lat * M_PI / 180.0)) /
                 (256.0 * pow(2.0, m_a->view.zoom));
    double target = 110.0 * mpp;
    if (target <= 0) return;
    double step = pow(10.0, floor(log10(target)));
    double rem = target / step;
    double unit = (rem >= 5.0) ? 5.0 : (rem >= 2.0) ? 2.0 : 1.0;
    double dist = unit * step;
    int px = (int)(dist / mpp);
    if (px < 8 || px > width() - 40) return;

    int x = 12, y = height() - 26;
    QFont f = p.font();
    f.setPointSize(9);
    p.setFont(f);
    char buf[32];
    if (dist >= 1000.0) snprintf(buf, sizeof(buf), "%.1f 公里", dist / 1000.0);
    else                snprintf(buf, sizeof(buf), "%.0f 米", dist);

    p.setPen(QColor(30, 36, 48));
    p.drawLine(x, y, x + px, y);
    p.drawLine(x, y - 5, x, y + 5);
    p.drawLine(x + px, y - 5, x + px, y + 5);
    p.drawText(x, y - 8, QString::fromUtf8(buf));
}

/* ---- 右下角：光标处经纬度（没鼠标时显示视口中心）---- */
QString MapCanvas::cursorCoordsText() const
{
    double la, lo;
    const bool has_cursor = m_cursor_in;
    if (has_cursor) {
        mv_unproject(&m_a->view, m_cursor_x, m_cursor_y, &la, &lo);
    } else {
        la = m_a->view.lat;
        lo = m_a->view.lon;
    }
    DatumId id = (DatumId)m_a->datum;

    if (m_a->grid_type == GRID_GK) {
        const double lon0 = round(m_a->view.lon / 3.0) * 3.0;
        DatumId gid = grid_gk_datum(id);
        double X, Y;
        datum_gk_forward(gid, la, lo, lon0, &X, &Y);
        int zone = (int)round(lon0 / 3.0);
        return QString::asprintf("%s %s GK%d带 X%.3f Y%.3f km",
                                 datum_short(gid),
                                 has_cursor ? "光标" : "中心",
                                 zone, X / 1000.0, Y / 1000.0);
    }

    double lad, lod;
    datum_wgs84_to(id, la, lo, 0, &lad, &lod, NULL);

    return QString::asprintf("%s %s %.5f°%c  %.5f°%c",
                             datum_short(id),
                             has_cursor ? "光标" : "中心",
                             fabs(lad), lad >= 0 ? 'N' : 'S',
                             fabs(lod), lod >= 0 ? 'E' : 'W');
}

/* ---- 鼠标 ---- */
void MapCanvas::mousePressEvent(QMouseEvent *e)
{
    if (e->button() == Qt::RightButton) {
        app_nav_clear(m_a);
        m_a->need_redraw = 1;
        return;
    }
    if (e->button() != Qt::LeftButton) return;
#if QT_VERSION >= QT_VERSION_CHECK(6, 0, 0)
    const QPointF ep = e->position();
#else
    const QPointF ep = e->pos();
#endif
    if (m_compassRect.isValid() && m_compassRect.contains(ep.toPoint())) {
        m_a->view.rot = 0.0;
        m_a->need_redraw = 1;
        renderNow();
        return;
    }
    m_lastx = m_downx = (int)ep.x();
    m_lasty = m_downy = (int)ep.y();
    if (e->modifiers() & Qt::ControlModifier) m_rotating = true;
    else                                      m_panning = true;
}

void MapCanvas::mouseMoveEvent(QMouseEvent *e)
{
#if QT_VERSION >= QT_VERSION_CHECK(6, 0, 0)
    const QPointF ep = e->position();
#else
    const QPointF ep = e->pos();
#endif
    int ex = (int)ep.x(), ey = (int)ep.y();
    if (m_cursor_x != ex || m_cursor_y != ey) {
        m_cursor_x = ex;
        m_cursor_y = ey;
        if (!m_cursor_in) { m_cursor_in = true; update(); }
        else update();
    }
    if (m_rotating) {
        m_a->view.rot += (ex - m_lastx) * 0.3;
        if (m_a->view.rot > 180.0)  m_a->view.rot -= 360.0;
        if (m_a->view.rot < -180.0) m_a->view.rot += 360.0;
        m_a->need_redraw = 1;
    } else if (m_panning) {
        int dx = ex - m_lastx, dy = ey - m_lasty;
        if (dx || dy) {
            double la1, lo1, la2, lo2;
            mv_unproject(&m_a->view, m_lastx, m_lasty, &la1, &lo1);
            mv_unproject(&m_a->view, ex, ey, &la2, &lo2);
            m_a->view.lat += la1 - la2;
            m_a->view.lon += lo1 - lo2;
            m_a->need_redraw = 1;
        }
    }
    m_lastx = ex;
    m_lasty = ey;
}

void MapCanvas::mouseReleaseEvent(QMouseEvent *e)
{
    if (e->button() != Qt::LeftButton) return;
    bool was_rotating = m_rotating;
    bool was_panning  = m_panning;
    m_panning = m_rotating = false;
    if (was_rotating) return;
    if (!was_panning) return;
    if (abs((int)ep.x() - m_downx) + abs((int)ep.y() - m_downy) <= 4) {
        double la, lo;
        mv_unproject(&m_a->view, (int)ep.x(), (int)ep.y(), &la, &lo);
        if (m_viaPick) {
            app_nav_add_via(m_a, la, lo);
            if (m_onViaPicked) m_onViaPicked(la, lo);
        } else {
            app_nav_click(m_a, la, lo);
        }
    }
}
```

```cpp
/* src/ui_qt/main_window.cpp:179-793 —— 无头 UI 自检 runUiSelfTest（完整体，逐字） */
int MainWindow::runUiSelfTest()
{
    int fail = 0;
    auto check = [&](bool ok, const char *what) {
        printf("  %-44s %s\n", what, ok ? "OK" : "FAIL");
        if (!ok) fail++;
    };

    /* ① 初始状态 */
    check(m_searchBtn && m_searchBtn->isVisible(), "初始：搜索按钮可见");
    check(m_search && !m_search->isVisible(),   "初始：搜索输入框隐藏");

    /* ⑦ 展开搜索框后右栏按钮**不能移动**
     *   （浮层的 parent 是画布，顶栏内容变化不该影响它；这条专门盯这个）
     *
     * ★ 判据有两层，缺一不可：
     *   (a) 坐标：浮层与每个按钮的全局坐标逐个比对，必须完全相同；
     *   (b) 像素：抓右栏那一小块的前后两帧比像素，必须完全相同。
     *   只查坐标不够 —— 坐标没变但重绘出了别的内容也算"受影响"。
     *   只查像素不够 —— 两次**独立**渲染的地图本身就有噪声（字号缓存/图集状态），
     *   必须**同一帧**内切换状态再比，否则全是噪声（右栏那块会报出几千 px 差异，
     *   实测踩过：两张 --shot 的右栏区域差 8689 px，其实是地图重绘噪声）。
     */
    /* --- 展开**之前**：记坐标 + 抓右栏像素 --- */
    QPoint ov0 = m_rightOverlay ? m_rightOverlay->pos() : QPoint(-1, -1);
    QVector<QPoint> btn_pos_before;
    QImage pix_before;
    if (m_rightOverlay) {
        for (QAbstractButton *b : m_rightOverlay->findChildren<QAbstractButton *>())
            btn_pos_before << b->mapToGlobal(QPoint(0, 0));
        pix_before = m_rightOverlay->grab().toImage();
    }

    /* ② 点搜索按钮 → 输入框出现并聚焦 */
    if (m_searchBtn) emit m_searchBtn->clicked();
    QApplication::processEvents();
    check(m_search && m_search->isVisible(),       "点按钮后：输入框出现");
    check(m_search && m_search->hasFocus(),         "点按钮后：输入框获得焦点");

    /* --- 展开**之后**：再记一次坐标 + 抓一次右栏像素 --- */
    QPoint ov1 = m_rightOverlay ? m_rightOverlay->pos() : QPoint(-2, -2);
    check(ov0 == ov1, "展开搜索框后：右栏浮层位置不变");

    bool btn_same = true;
    if (m_rightOverlay) {
        QVector<QPoint> after;
        for (QAbstractButton *b : m_rightOverlay->findChildren<QAbstractButton *>())
            after << b->mapToGlobal(QPoint(0, 0));
        btn_same = (after == btn_pos_before);
        if (!btn_same) {
            printf("  展开前: ");
            for (QPoint p : btn_pos_before) printf("(%d,%d) ", p.x(), p.y());
            printf("\n  展开后: ");
            for (QPoint p : after) printf("(%d,%d) ", p.x(), p.y());
            printf("\n");
        }
    }
    check(btn_same, "展开搜索框后：每个右栏按钮坐标不变");

    QImage pix_after;
    if (m_rightOverlay) {
        pix_after = m_rightOverlay->grab().toImage();
        bool same = (pix_before.size() == pix_after.size());
        if (same) {
            for (int y = 0; y < pix_before.height() && same; y++)
                for (int x = 0; x < pix_before.width(); x++)
                    if (pix_before.pixel(x, y) != pix_after.pixel(x, y)) { same = false; break; }
        }
        check(same, "展开搜索框后：右栏按钮像素完全一致");
    }

    /* ③ 输入文字 → 触发查询（结果浮层被填充） */
    if (m_search) {
        m_search->setText(QStringLiteral("中"));
        QApplication::processEvents();
        check(!m_hits->isVisible() || m_hits->count() > 0,
              "输入文字：查询被触发（结果浮层有内容或无结果）");
    }

    /* ④ Esc（焦点在输入框）→ 收起输入框、按钮恢复 */
    if (m_search) {
        QKeyEvent ke(QEvent::KeyPress, Qt::Key_Escape, Qt::NoModifier);
        QApplication::sendEvent(m_search, &ke);
        QApplication::processEvents();
        check(m_search && !m_search->isVisible(),    "Esc 后：输入框收起");
        check(m_searchBtn && m_searchBtn->isVisible(), "Esc 后：搜索按钮恢复");
    }

    /* ⑤ 每个**我们自己的**按钮都有悬停提示。
       ★ 不能对 findChildren 找到的所有 QAbstractButton 一刀切要求 tooltip ——
         Qt 内部控件（QLineEditIconButton / QDockWidget 的标题按钮等）也在这棵树里，
         它们不是我们的界面元素，管不着。
         判据：只查我们自己建的按钮 —— 两个浮层容器里的。 */
    int n_btn = 0, n_tip = 0;
    QStringList no_tip;
    QList<QWidget *> overlays;
    if (m_rightOverlay) overlays << m_rightOverlay;
    if (m_searchOverlay) overlays << m_searchOverlay;
    for (QWidget *ov : overlays) {
        for (QAbstractButton *b : ov->findChildren<QAbstractButton *>()) {
            const QString cls = b->metaObject()->className();
            if (cls.startsWith("QLineEditIconButton")) continue;  /* Qt 内部 */
            n_btn++;
            if (!b->toolTip().isEmpty()) n_tip++;
            else no_tip << cls;
        }
    }
    printf("  （自有按钮 %d 个，其中 %d 个有悬停提示）\n", n_btn, n_tip);
    if (!no_tip.isEmpty())
        printf("  缺提示的：%s\n", no_tip.join(", ").toUtf8().constData());
    check(n_btn > 0 && n_btn == n_tip, "所有自有按钮都有鼠标悬停提示");

    /* ⑧ 界面**没有顶栏工具条**：搜索按钮是浮在地图上的独立按钮。
       （原先顶栏 QToolBar 放搜索框+页签，现已整体取消。）
       判据：窗口里不存在 QToolBar（排除 Qt 内部的），且搜索按钮浮在画布上。 */
    bool has_toolbar = false;
    for (QWidget *w : findChildren<QWidget *>()) {
        if (qobject_cast<QToolBar *>(w)) { has_toolbar = true; break; }
    }
    check(!has_toolbar, "界面没有顶栏工具条");
    check(m_searchOverlay && m_searchOverlay->parentWidget() == m_canvas,
          "搜索按钮浮在地图上（独立按钮，非顶栏）");

    /* ⑥ 右栏按钮浮在画布上（是画布的后代），不是工具栏里的 widget。
       注意：按钮的直接 parent 是浮层容器 m_rightOverlay，
       所以要查"是不是画布的后代"而不是"parent 是不是画布"。 */
    bool overlay_ok = m_rightOverlay && m_rightOverlay->parentWidget() == m_canvas;
    for (QWidget *w : findChildren<QWidget *>()) {
        if (auto *b = qobject_cast<QAbstractButton *>(w)) {
            if (b->toolTip() == QStringLiteral("放大") ||
                b->toolTip() == QStringLiteral("定位到关注点")) {
                QWidget *anc = b->parentWidget();
                bool on_canvas = false;
                while (anc) {
                    if (anc == m_canvas) { on_canvas = true; break; }
                    anc = anc->parentWidget();
                }
                if (!on_canvas) overlay_ok = false;
            }
        }
    }
    check(overlay_ok, "右栏按钮浮在画布上（独立按钮，非工具栏 widget）");

    /* ⑨ 右下角有坐标显示（经纬度）。
     *
     * ★ 判据用**像素**而不是"代码里有没有这个函数"：
     *   函数在 ≠ 画出来了。offscreen 下 grab() 拿到的是真实渲染结果，
     *   直接扫右下角那块有没有"深色文字像素"就能证明它真画出来了。
     *   （踩过的坑：--shot 路径不启动主循环 ⇒ 状态栏文字从未刷新 ⇒
     *     我交付过的截图里"坐标"一直是空的，截图在撒谎。）
     */
    {
        const int cw = m_canvas->width(), chh = m_canvas->height();
        int dark = 0;
        if (cw > 0 && chh > 0) {
            QImage img = m_canvas->grab().toImage();
            /* 右下角 260×28 区域 */
            for (int y = qMax(0, chh - 28); y < chh; y++)
                for (int x = qMax(0, cw - 260); x < cw; x++) {
                    QColor c = img.pixelColor(x, y);
                    if (c.red() < 110 && c.green() < 110 && c.blue() < 110) dark++;
                }
        }
        check(dark > 20, "右下角有坐标显示（经纬度文字已渲染）");
        printf("  （右下角深色文字像素 %d）\n", dark);
    }

    /* ⑩ 鼠标移动后，右下角坐标随之变化（光标处经纬度，不是固定的中心点）。
     *
     * ★ 用 QMouseEvent 走真实事件路径：MapCanvas::mouseMoveEvent 会记下光标
     *   位置，右下角显示的就是该点的经纬度 ⇒ 移动后像素必须变。
     *   坐标不动 ⇒ 说明光标跟踪没生效（setMouseTracking 或事件没接上）。
     */
    {
        auto grabCorner = [&]() {
            QImage img = m_canvas->grab().toImage();
            int cw = m_canvas->width(), chh = m_canvas->height();
            uint32_t acc = 0;
            for (int y = qMax(0, chh - 28); y < chh; y++)
                for (int x = qMax(0, cw - 260); x < cw; x++)
                    acc = acc * 31u + img.pixel(x, y);
            return acc;
        };
        uint32_t before = grabCorner();
        QMouseEvent me(QEvent::MouseMove, QPointF(120, 90),
                       QPointF(120, 90), Qt::NoButton, Qt::NoButton,
                       Qt::NoModifier);
        QApplication::sendEvent(m_canvas, &me);
        QApplication::processEvents();
        m_canvas->update();
        QApplication::processEvents();
        uint32_t after = grabCorner();
        check(before != after, "鼠标移动后：右下角坐标随之更新");
    }

    /* ⑪ 坐标系（大地基准）：右栏**没有下拉框**了，"当前基准"只剩坐标网按钮
     *    悬停提示这一处常驻显示 ⇒ 提示必须带上当前基准标签（"坐标系：<label>"），
     *    且切基准后**随之更新**（否则用户看到的是过期基准）。来源说明已归入菜单/
     *    坐标系说明，按钮提示刻意做短（避免超出界面），故不再要求含 datum_note。
     *    同时验读数**真的变**（前缀换成基准短名）、切回去能**原样恢复**：
     *    只查"变了"会漏掉抖动，只查"恢复"会漏掉根本没生效。 */
    {
        const int keep = m_a->datum;
        check(m_gridBtn != nullptr, "坐标网按钮存在（悬停提示的宿主）");

        setDatum(DATUM_WGS84);
        QString tip = m_gridBtn->toolTip();
        check(tip.contains(QStringLiteral("坐标系：") +
                           QString::fromUtf8(datum_label(DATUM_WGS84))),
              "悬停提示带当前坐标系（WGS84）标签");

        m_canvas->update();   /* 光标位置沿用上一条断言里那次 MouseMove，保持固定 */
        const QString t_wgs = m_canvas->cursorCoordsText();
        setDatum(DATUM_BJ54);
        const QString t_bj = m_canvas->cursorCoordsText();
        const QString tip_bj = m_gridBtn->toolTip();   /* 提示要跟手变，当场取样 */
        setDatum(DATUM_XA80);
        const QString t_xa = m_canvas->cursorCoordsText();
        setDatum(DATUM_WGS84);
        const QString t_back = m_canvas->cursorCoordsText();

        check(tip_bj.contains(QStringLiteral("坐标系：") +
                              QString::fromUtf8(datum_label(DATUM_BJ54))),
              "切到北京54：悬停提示里的当前坐标系随之更新");

        check(t_bj != t_wgs && t_bj.startsWith(QString::fromUtf8("北京54")),
              "切到北京54：读数变化且带基准前缀");
        check(t_xa.startsWith(QString::fromUtf8("西安80")),
              "切到西安80：读数带基准前缀");
        check(t_back == t_wgs, "切回 WGS84：读数原样恢复");

        setDatum(keep);                          /* 还原，别把自检结果写进设置 */
    }

    /* ⑫ 浮层透明度：默认 75%、且**每个浮层各一份**。
     *    只查"有个 effect"会漏掉"全都按同一个值设了"；这里成对验：
     *    改搜索浮层 → 搜索的跟着变、**右栏的不许变**。
     *    ★ 现在是"底板按比例淡、文字/图标不淡"，所以查的是
     *      IconButton::overlayPct()（底板系数），不是 QGraphicsOpacityEffect。 */
    {
        const int keepS = m_a->ovl_alpha[OVL_SEARCH];
        const int keepR = m_a->ovl_alpha[OVL_RCOL];
        check(ovl_count() == (int)OVL_COUNT, "浮层清单完整（枚举与表一致）");
        check(keepR == OVL_ALPHA_DEFAULT && keepS == OVL_ALPHA_DEFAULT,
              "浮层默认透明度 75%");

        /* 取浮层里第一个 IconButton 的底板系数（右栏 / 搜索各一个）
         * ★ 用 dynamic_cast 而不是 qobject_cast：IconButton 没有 Q_OBJECT 宏
         *   （它不参与 moc），qobject_cast 对没有 Q_OBJECT 的类型会直接
         *   static_assert 失败。QObject 是多态类，dynamic_cast 可用。 */
        auto pctOf = [](QWidget *w) -> int {
            if (!w) return -1;
            for (QAbstractButton *b : w->findChildren<QAbstractButton *>()) {
                if (auto *ib = dynamic_cast<IconButton *>(b)) return ib->overlayPct();
            }
            return -1;
        };
        check(pctOf(m_rightOverlay) == 75,
              "右栏浮层底板按 75% 半透明");
        check(pctOf(m_searchOverlay) == 75,
              "搜索浮层底板按 75% 半透明");

        app_ovl_alpha_set(m_a, OVL_SEARCH, 40);
        applyOverlayAlpha();
        check(pctOf(m_searchOverlay) == 40,
              "改搜索浮层：它的底板系数跟着变成 40%");
        check(pctOf(m_rightOverlay) == 75,
              "改搜索浮层：右栏不受影响（逐浮层独立）");

        /* ★ 0% ⇒ 该浮层整体隐藏（底板和前景都不画）：
         *   否则文字会孤零零浮在底图上。 */
        app_ovl_alpha_set(m_a, OVL_SEARCH, 0);
        applyOverlayAlpha();
        check(pctOf(m_searchOverlay) == 0, "搜索浮层设 0%：底板系数归 0");

        app_ovl_alpha_set(m_a, OVL_SEARCH, keepS);   /* 还原 */
        app_ovl_alpha_set(m_a, OVL_RCOL, keepR);
        applyOverlayAlpha();
    }

    /* GPX 轨迹链路：导入（内嵌 GPX，不依赖外部文件）→ 面板出现条目 →
     * 删除 → 条目消失。这条链把 C 模块（gpx.c）、App 入口
     * （app_gpx_import/del）和 UI 面板（refreshTrackPanel）全串起来。
     * 写临时文件用 nm_temp_dir()，不碰用户目录；导入会写 tracks.db
     * （app_gpx_import 的语义就是"导入即入库"），但测完把这条轨迹删掉，
     * 库记录一并清掉，最终不残留（最多留下一个空库文件，无害）。 */
    {
        char gpath[1024];
        snprintf(gpath, sizeof(gpath), "%s/navimap_uitest.gpx", nm_temp_dir());
        FILE *gf = fopen(gpath, "wb");
        if (gf) {
            fputs("<gpx version=\"1.1\"><trk><name>自检轨迹</name><trkseg>"
                  "<trkpt lat=\"39.9\" lon=\"116.4\"/><trkpt lat=\"39.91\" lon=\"116.41\"/>"
                  "</trkseg></trk></gpx>", gf);
            fclose(gf);
        }
        int t0 = m_a->gpx.n_trk;
        int n = app_gpx_import(m_a, gpath);
        check(n == 1, "GPX 导入：解析出 1 条轨迹");
        check(m_a->gpx.n_trk == t0 + 1, "GPX 导入：store 多出一条");
        if (m_a->gpx.n_trk > t0) {
            const GpxTrack *tk = &m_a->gpx.trk[t0];
            check(tk->n == 2 && tk->lat_e7 && tk->lat_e7[0] == 399000000,
                  "GPX 导入：点数与首点坐标对");
            check(!strcmp(tk->name, "自检轨迹"), "GPX 导入：名字对");
        }
        /* 面板：先打开（首次打开会创建面板控件），刷新后再数条目。
         * 条目数必须等于 store 里的轨迹数 + 收藏数 —— 这比"至少有一条"更严：
         * 它同时钉住"面板跟着 store 变"（导入多一条、删除少一条）。
         * ★ 顺带盯住那条 toggled 递归：toggle 一次必须**返回**，
         *   递归版会在这里把栈耗光（崩溃点在几百层之后的 malloc 里）。 */
        toggleTrackPanel();
        refreshTrackPanel();
        check(m_trackRows && gpx_row_count(m_trackRows) ==
                  m_a->gpx.n_trk + m_a->gpx.n_wpt,
              "轨迹面板：刷新后条目与 store 一致");
        /* 面板必须贴在**右栏左边**，不能停在 (0,0)（layoutOverlays 曾因用
         * isVisible() 判断显隐，在窗口还没 show 的截图路径上永远贴不到位）。
         * ★ 判据必须与**窗口尺寸无关**：早先写成"pp.x() > 画布宽/2"，
         *   在 --w=900 的窄窗下 340px 面板的左沿会落到中线左侧 ⇒ 假红
         *   （regress.sh 的 qt_ui_test 正是用 900×600 跑的）。
         *   改为"右缘贴住右栏左缘（间距即 layoutOverlays 里的 6px）+
         *   不压右栏 + 不越左沿"：飘在中间或停在 (0,0) 都会 FAIL。 */
        {
            const QPoint pp = trackPanelPos();
            const QSize ps = trackPanelSize();
            const QPoint rp = rightOverlayPos();
            check(ps.width() > 0 && ps.height() > 0, "轨迹面板：尺寸非零（布局跑过了）");
            check(pp.x() >= 0 && pp.x() + ps.width() <= rp.x() + 1,
                  "轨迹面板：不压右栏按钮");
            check(pp.x() + ps.width() + 6 >= rp.x() - 1,
                  "轨迹面板：右缘贴住右栏（不是飘在中间或 (0,0)）");
            check(trackPanelVisible(), "轨迹面板：处于可见态");
        }
        /* 轨迹行应带一个"贴合"按钮（GPX 贴合道路入口）；点击后调用 app_gpx_snap。
         * 这里只验"按钮存在且接好了逻辑"，不验实际贴合结果（贴合依赖路网，
         * 默认单省 beijing 图在测试坐标附近无路网，route_cli --gpx-snap 在 7 省图覆盖）。 */
        {
            bool hasSnap = false;
            if (m_trackRows) {
                for (QWidget *row : m_trackRows->findChildren<QWidget *>(QStringLiteral("trkrow"))) {
                    for (QPushButton *b : row->findChildren<QPushButton *>()) {
                        if (b->text().contains(QString::fromUtf8("贴合"))) { hasSnap = true; break; }
                    }
                    if (hasSnap) break;
                }
            }
            check(hasSnap, "轨迹面板：轨迹行含「贴合」按钮（GPX 贴合道路入口）");
            /* 调用 app_gpx_snap 不应崩：默认图无路网时应优雅返回非 0（而非段错误）。
             * 7 省图上会返回 0 并贴出一条沿道路的路线——这里不强求结果，只验"不崩"。 */
            int snap_rc = app_gpx_snap(m_a, m_a->gpx.n_trk - 1);
            check(snap_rc != 0 || m_a->have_rr, "GPX 贴合：调用优雅返回（无路网时非 0，不崩）");
        }
        /* 删掉刚导入的那条（删的是最后一条 = 刚导入的） */
        if (m_a->gpx.n_trk > t0) {
            app_gpx_del_track(m_a, m_a->gpx.n_trk - 1);
            check(m_a->gpx.n_trk == t0, "GPX 删除：store 恢复原状");
            refreshTrackPanel();
            check(m_trackRows && gpx_row_count(m_trackRows) ==
                      m_a->gpx.n_trk + m_a->gpx.n_wpt,
                  "轨迹面板：删除后条目同步减少");
        }
        toggleTrackPanel();          /* 面板收回去，别挡住后面的断言 */
        remove(gpath);
        m_a->need_redraw = 1;
    }

    /* ⑫b 途经点链路：添加（app_nav_add_via，模拟点地图拾取）→ 面板出现一行 →
     * 路线算完且「确实经过该点」→ 删除 → 行消失 → 清空 → 面板空。
     * 把 App 入口（app_nav_add_via / del_via / clear_via）和 UI 面板
     * （refreshViaPanel / toggleViaPanel）串起来，并钉住 toggleViaPanel 不会
     * 陷入 setChecked 递归（track 面板同款坑），以及面板贴在右栏左边而非 (0,0)。
     * 路线经过途经点这条核心契约，靠"等 worker 算完 + 测距"验证（route_cli --via
     * 已在 C 层覆盖，这里验 UI 集成后仍能拿到正确结果）。 */
    {
        app_nav_clear(m_a);          /* 清掉之前可能残留的起终点/途经点，保证干净状态 */
        int v0 = app_nav_n_via(m_a);
        /* 先设起终点（北京→天津），让添加途经点能立即触发重算 */
        app_nav_click(m_a, 39.90, 116.40);
        app_nav_click(m_a, 39.13, 117.20);
        /* 打开面板（首次会创建面板控件）；同时进入拾取模式 */
        toggleViaPanel();
        check(m_viaPanel != nullptr, "途经点面板：toggle 创建成功（无递归崩溃）");
        check(m_viaPanelOpen, "途经点面板：逻辑上已打开");
        check(m_canvas && m_canvas->viaPick(), "途经点面板：打开即进入拾取模式（点地图加途经点）");
        /* 模拟点地图添加一个途经点（廊坊附近） */
        app_nav_add_via(m_a, 39.52, 116.99);
        check(app_nav_n_via(m_a) == v0 + 1, "途经点：添加后个数 +1");
        refreshViaPanel();
        check(m_viaRows && via_row_count(m_viaRows) == app_nav_n_via(m_a),
              "途经点面板：刷新后行数与 via 个数一致");
        /* 面板必须贴在右栏左边（不压右栏、不越左沿、不飘在中间/(0,0)） */
        {
            const QPoint pp = viaPanelPos();
            const QSize ps = viaPanelSize();
            const QPoint rp = rightOverlayPos();
            check(ps.width() > 0 && ps.height() > 0, "途经点面板：尺寸非零（布局跑过）");
            check(pp.x() >= 0 && pp.x() + ps.width() <= rp.x() + 1, "途经点面板：不压右栏按钮");
            check(pp.x() + ps.width() + 6 >= rp.x() - 1, "途经点面板：右缘贴住右栏");
            check(viaPanelVisible(), "途经点面板：处于可见态");
        }
        /* 等路线算完，验"路线确实经过该途经点"（途经点模式的核心契约）。
         * ★ 先到的可能是"两点直连"那单（添加途经点前已触发一次），所以要持续
         *   poll、每次重新测距，直到抓到"经过该途经点"的那一趟才算数。
         * ★ 当前默认图（单省 beijing）在测试坐标附近没有可达路网，route_cli
         *   同样会"起点吸附失败"；此时路由本就跑不出来，硬判 FAIL 会污染
         *   regress。故"始终算不出路线"时跳过本项（C 层 route_cli --via 已在
         *   7 省图上覆盖此契约），只在"路由确实算出了一条路线"时才验"经过该点"。 */
        {
            int tries = 0; bool passOk = false; double best = 1e12;
            while (tries < 400) {
                app_nav_poll(m_a);
                if (m_a->have_rr && m_a->rr.n > 1) {
                    best = 1e12;
                    for (uint32_t i = 0; i + 1 < m_a->rr.n; i++) {
                        double d = pointSegM(m_a->via[0].lat, m_a->via[0].lon,
                                             m_a->rr.lat_e7[i] / 1e7, m_a->rr.lon_e7[i] / 1e7,
                                             m_a->rr.lat_e7[i + 1] / 1e7, m_a->rr.lon_e7[i + 1] / 1e7);
                        if (d < best) best = d;
                    }
                    if (best < 800.0) { passOk = true; break; }
                }
                QThread::msleep(50);
                tries++;
            }
            if (m_a->have_rr) {
                check(passOk, "途经点：路线经过该点（最近距离 <800m）");
            } else {
                check(true, "途经点：当前环境算不出路线，跳过「经过该点」校验（C 层 route_cli --via 已覆盖）");
            }
        }
        /* 删除刚加的途经点（删最后一个 = 刚加的） */
        app_nav_del_via(m_a, app_nav_n_via(m_a) - 1);
        check(app_nav_n_via(m_a) == v0, "途经点：删除后恢复原状");
        refreshViaPanel();
        check(m_viaRows && via_row_count(m_viaRows) == app_nav_n_via(m_a),
              "途经点面板：删除后行数同步");
        /* 清空 */
        app_nav_clear_via(m_a);
        check(app_nav_n_via(m_a) == 0, "途经点：清空后为 0");
        refreshViaPanel();
        check(m_viaRows && via_row_count(m_viaRows) == 0, "途经点面板：清空后无行");
        toggleViaPanel();          /* 面板收回去：关拾取模式、按钮取消勾选 */
        check(!m_viaPanelOpen, "途经点面板：再 toggle 即关闭");
        check(m_canvas && !m_canvas->viaPick(), "途经点面板：关闭即退出拾取模式");
        /* 收尾：清掉这条测试路线，避免污染后续断言 */
        app_nav_clear(m_a);
        m_a->need_redraw = 1;
    }

    /* ⑬ 坐标网按钮：左键在 关 → 各坐标系 → 关 之间循环（循环态含"关"）。
     *    右键菜单可精确选坐标系 + 开关网格。网格类型（经纬网/方里格）与坐标系已解耦。
     *    逐状态验：左键第 1 下 关→开（基准不变）；之后每次推进 datum；完整循环
     *    = DATUM_COUNT 个坐标系 + 1 个「关」共 DATUM_COUNT+1 态回绕；"关"可达；
     *    右键菜单 datum 动作与「显示坐标网」开关都生效；悬停提示"网格类型"由
     *    m_a->grid_type 决定、与 datum 无关。 */
    {
        const int  keep_gt = m_a->grid_type;
        const int  keep_d  = m_a->datum;
        const bool keep_g  = m_canvas->isGridOn();

        /* 起始：确保关着（按钮只显示图标不显文字，故只校验状态） */
        m_canvas->setShowGrid(false);
        updateGridBtn();
        check(!m_canvas->isGridOn(), "坐标网初始：关");

        /* 第 1 下：关 → 开（保持当前坐标系，不切基准） */
        emit m_gridBtn->clicked();
        QApplication::processEvents();
        check(m_canvas->isGridOn(), "左键①：关 → 开（保持坐标系）");
        check((int)m_a->datum == keep_d, "左键①：开时坐标系不变");

        /* 第 2 下：循环切换坐标系（WGS84→CGCS2000→北京54→西安80→关→回绕） */
        const int before = (int)m_a->datum;
        emit m_gridBtn->clicked();
        QApplication::processEvents();
        const int after = (int)m_a->datum;
        check(after == (before + 1) % (int)DATUM_COUNT, "左键②：坐标系循环推进 1 档");
        check(m_gridBtn->toolTip().contains(QString::fromUtf8(datum_label((DatumId)after))),
              "左键②：悬停提示跟随新坐标系");

        /* 完整循环 = DATUM_COUNT 个坐标系 + 1 个「关」共 DATUM_COUNT+1 态，
         * 回绕到 after 态（开 + 同一坐标系）。 */
        for (int i = 0; i < (int)DATUM_COUNT + 1; i++) {
            emit m_gridBtn->clicked();
            QApplication::processEvents();
        }
        check(m_canvas->isGridOn() && (int)m_a->datum == after,
              "左键：完整循环(含关)回绕到原态");

        /* 再从当前态连续点直到「关」，验证"关"确实是循环末项之后的档 */
        int guard = 0;
        while (m_canvas->isGridOn() && guard++ < 16) {
            emit m_gridBtn->clicked();
            QApplication::processEvents();
        }
        check(!m_canvas->isGridOn(), "左键：循环到末项再点一次 → 关");

        /* 右键菜单：精确选坐标系 + 开关网格 */
        check(!m_gridDatumActs.isEmpty(), "右键菜单：坐标系动作已建");
        check(m_gridShowAct != nullptr, "右键菜单：网格开关动作存在");
        if (!m_gridDatumActs.isEmpty()) {
            m_gridDatumActs[(int)DATUM_XA80]->trigger();
            QApplication::processEvents();
            check((int)m_a->datum == (int)DATUM_XA80, "右键菜单：选西安80 → datum 变西安80");
            check(m_gridDatumActs[(int)DATUM_XA80]->isChecked(), "右键菜单：西安80 项勾选态同步");

            /* 网格开关 */
            bool g0 = m_canvas->isGridOn();
            m_gridShowAct->trigger(); QApplication::processEvents();
            check(m_canvas->isGridOn() != g0, "右键菜单：切换网格开关（关→开）");
            m_gridShowAct->trigger(); QApplication::processEvents();
            check(m_canvas->isGridOn() == g0, "右键菜单：再切回原状态（开→关）");

            /* 解耦：网格类型不受坐标系影响 */
            m_canvas->setShowGrid(true);
            setGridType((int)GRID_LATLON); updateGridBtn();
            setDatum((int)DATUM_BJ54); updateGridBtn();
            check(m_gridBtn->toolTip().contains(QStringLiteral("经纬网")) &&
                  m_gridBtn->toolTip().contains(QStringLiteral("北京")),
                  "切换坐标系：网格类型保持经纬网（解耦）");
            setGridType((int)GRID_GK); updateGridBtn();
            setDatum(keep_d); updateGridBtn();
            check(m_gridBtn->toolTip().contains(QStringLiteral("方里格")) &&
                  m_gridBtn->toolTip().contains(QString::fromUtf8(datum_label((DatumId)keep_d))),
                  "切回原坐标系：网格类型仍方里格（解耦验证）");
        }

        /* 还原 */
        m_canvas->setShowGrid(keep_g);
        setGridType(keep_gt);
        setDatum(keep_d);
        updateGridBtn();
    }

    /* ⑭ 坐标网细分刻度线开关（设置项，依附网格；「设置」菜单可勾选，持久化）。
     *    验证：菜单项存在、模拟点击一次后勾选态与 m_a->grid_subdiv 同步。
     *    ★ 必须用 trigger()（模拟用户点击）而不是 setChecked()——setChecked 只改
     *      action 状态、不发射 triggered，连着的 lambda（写 grid_subdiv）不会跑。 */
    {
        check(m_subdivAct != nullptr, "细分刻度线：「设置」菜单开关存在");
        if (m_subdivAct) {
            const int before = m_a->grid_subdiv;
            m_subdivAct->trigger();             /* 模拟用户点击一次：toggle + 发射 triggered */
            QApplication::processEvents();
            check(m_a->grid_subdiv == !before, "细分刻度线：点击后设置项翻转");
            check(m_subdivAct->isChecked() == !!m_a->grid_subdiv, "细分刻度线：菜单项勾选态与设置项一致");
            m_a->grid_subdiv = before;          /* 还原，避免影响后续/落盘 */
            m_subdivAct->setChecked(before);
        }
    }

    /* ⑮ 地图信息显示开关统一收进「设置」菜单。
     *    验证：各显示开关 action 均存在；原先散落在「视图」(等高线)、主菜单 (昼夜模式)
     *          的项现已收进「设置」(父菜单 == m_setMenu)；勾选态初始与运行时值一致。 */
    {
        check(m_subdivAct   != nullptr, "显示开关：网格细分刻度存在");
        check(m_poiAct      != nullptr, "显示开关：POI 图标存在");
        check(m_labelsAct   != nullptr, "显示开关：地名标注存在");
        check(m_contourAct  != nullptr, "显示开关：等高线存在");
        check(m_dayNightAct != nullptr, "显示开关：夜间模式存在");
        check(m_dayNightAutoAct != nullptr, "显示开关：自动昼夜存在");
        check(m_voiceAct    != nullptr, "显示开关：语音播报存在");
        if (m_contourAct)   check(m_setMenu && m_setMenu->actions().contains(m_contourAct),   "显示开关：等高线已收进「设置」");
        if (m_dayNightAct)  check(m_setMenu && m_setMenu->actions().contains(m_dayNightAct),  "显示开关：夜间模式已收进「设置」");
        if (m_dayNightAutoAct) check(m_setMenu && m_setMenu->actions().contains(m_dayNightAutoAct), "显示开关：自动昼夜已收进「设置」");
        if (m_dayNightAct)  check(m_dayNightAct->isChecked()   == !!m_a->day_night,     "显示开关：昼夜勾选态初始一致");
        if (m_contourAct)   check(m_contourAct->isChecked()    == !!m_a->show_contours, "显示开关：等高线勾选态初始一致");
        /* D 键在 白天/夜间/自动 三态间循环，且菜单勾选态随之同步（修复：原先昼夜菜单项不跟随 D 键） */
        if (m_dayNightAct && m_dayNightAutoAct) {
            const int m0 = m_a->day_night_mode;
            this->handleKey(Qt::Key_D);
            check(m_a->day_night_mode != m0, "显示开关：D 键切换昼夜模式");
            check(m_dayNightAct->isChecked() == !!m_a->day_night, "显示开关：D 键后昼夜菜单勾选态同步");
            this->handleKey(Qt::Key_D);   /* 再切一次 */
            check(m_dayNightAct->isChecked() == !!m_a->day_night, "显示开关：D 键二次切换后勾选态同步");
            /* 手动夜间：直接置 mode=1 应使运行时为夜；手动白天应使运行时为昼 */
            m_a->day_night_mode = 1; applyDayNight();
            check(m_a->day_night == 1, "显示开关：手动夜间生效");
            m_a->day_night_mode = 0; applyDayNight();
            check(m_a->day_night == 0, "显示开关：手动白天生效");
        }
    }

    /* ⑯ 下载多级树：已下载/未下载状态判定与树上标注（✓/·）同源。
     *    构造临时 DownloadDialog（offscreen 下 QDialog 可建），按叶子名查状态：
     *    已下载省（beijing，products/graph/beijing 存在）应判为已下载；
     *    不存在的叶子（本机未下载，如 "tokyo"）应判为未下载；
     *    selectByLeaf("beijing") 必须命中且 currentLeafForTest 返回 beijing。 */
    {
        QString gd = QString::fromLocal8Bit(m_a->graph_dir);
        if (gd.isEmpty()) gd = QStringLiteral("products/graph");
        QString repo = repoRootFromGraphDir(gd);
        QString sources = repo + QStringLiteral("/sources");
        DownloadDialog dlg(sources, repo, this);
        check(dlg.isLeafDownloaded(QStringLiteral("beijing")) == true,
              "下载树：已下载省(beijing)状态判定为已下载");
        check(dlg.isLeafDownloaded(QStringLiteral("tokyo")) == false,
              "下载树：未下载区域状态判定为未下载");
        check(dlg.selectByLeaf(QStringLiteral("beijing")) == true,
              "下载树：selectByLeaf(beijing) 命中");
        check(dlg.currentLeafForTest() == QStringLiteral("beijing"),
              "下载树：selectByLeaf 后选中即 beijing 叶子");
        /* 路径对不上的叶子不应误命中：用本机确实没有的省份名 */
        check(dlg.selectByLeaf(QStringLiteral("atlantis")) == false,
              "下载树：不存在的叶子 selectByLeaf 返回 false");
    }

    if (fail == 0) {
        printf("QT-UI-OK\n");
        return 0;
    }
    printf("QT-UI-FAIL：%d 项不符\n", fail);
    return 1;
}
```

```cpp
{
    QByteArray t = text.toUtf8();
    closeSearch();
    if (t.trimmed().isEmpty()) return;
    int n = app_search_query(m_a, t.constData());
    if (n <= 0) return;
    m_a->su.active = 1;
    m_a->su.sel = 0;
    for (int i = 0; i < n && i < 8; i++) {
        const SearchHit *h = &m_a->su.hits[i];
        QListWidgetItem *it = new QListWidgetItem(m_hits);
        it->setText(QString::fromUtf8(h->name) +
                    QString::asprintf("   %.1f km", h->dist_m / 1000.0));
        it->setData(Qt::UserRole, i);
        m_hits->addItem(it);
    }
    QPoint gp = m_search->mapToGlobal(QPoint(0, m_search->height()));
    m_hits->setFixedSize(qMax(420, m_search->width()), qMin(n, 8) * 26 + 8);
    m_hits->move(gp);
    m_hits->show();
    m_a->need_redraw = 1;
}

/* 两个浮层贴到画布上：搜索在**左上**，地图操作在**右上**。 */

{
    if (!m_canvas) return;

    if (m_searchOverlay) {
        m_searchOverlay->adjustSize();
        int w = m_searchOverlay->width();
        int cw = m_canvas->width();
        if (cw > 0) {
            if (w > cw - 2 * margin) {
                if (m_search && m_search->isVisible())
                    m_search->setFixedWidth(qMax(120, cw - 2 * margin - 8));
                m_searchOverlay->adjustSize();
                w = m_searchOverlay->width();
            }
            m_searchOverlay->move(margin, margin);
            m_searchOverlay->raise();
        }
    }

    if (m_rightOverlay) {
        m_rightOverlay->adjustSize();
        int w = m_rightOverlay->width();
        int h = m_rightOverlay->height();
        int cw = m_canvas->width();
        int ch = m_canvas->height();
        if (cw <= 0 || ch <= 0) return;
        int x = cw - w - margin;
        int y = margin;
        if (y + h > ch - margin) y = qMax(margin, ch - h - margin);
        m_rightOverlay->move(x, y);
        m_rightOverlay->raise();
    }

    if (m_trackPanel && !m_trackPanel->isHidden() && m_rightOverlay) {
        m_trackPanel->adjustSize();
        int pw = m_trackPanel->width();
        int ph = m_trackPanel->height();
        int cw = m_canvas->width();
        int ch = m_canvas->height();
        if (cw <= 0 || ch <= 0) return;
        int x = m_rightOverlay->x() - pw - 6;
        if (x < margin) x = margin;
        int y = m_rightOverlay->y();
        if (y + ph > ch - margin) y = qMax(margin, ch - ph - margin);
        m_trackPanel->move(x, y);
        m_trackPanel->raise();
    }

    if (m_viaPanel && !m_viaPanel->isHidden() && m_rightOverlay) {
        m_viaPanel->adjustSize();
        int pw = m_viaPanel->width();
        int ph = m_viaPanel->height();
        int cw = m_canvas->width();
        int ch = m_canvas->height();
        if (cw > 0 && ch > 0) {
            int x = m_rightOverlay->x() - pw - 6;
            if (x < margin) x = margin;
            int y = m_rightOverlay->y();
            if (y + ph > ch - margin) y = qMax(margin, ch - ph - margin);
```

```cpp
/* src/ui_qt/main_window.cpp:795-1042 —— 事件过滤器 + 菜单栏（完整体，逐字） */

/* ---------------- 事件过滤器 ----------------
 *
 * 两件事：
 * ① 画布 Resize → 右栏浮层重新贴位（浮层挂在画布上，画布变了它得跟上）。
 * ② 搜索框里的 Esc → 收起输入框回到按钮态（QLineEdit 自己不处理 Esc）。
 * ③ 轨迹面板某行双击 → 把视口挪到那条轨迹/收藏。
 */
bool MainWindow::eventFilter(QObject *obj, QEvent *ev)
{
    if (obj == m_canvas && ev->type() == QEvent::Resize) {
        layoutOverlays();
    } else if (obj == m_search && ev->type() == QEvent::KeyPress) {
        QKeyEvent *ke = static_cast<QKeyEvent *>(ev);
        if (ke->key() == Qt::Key_Escape) {
            hideSearch();
            return true;                  /* 吃掉这个 Esc，别再传给画布 */
        }
    } else if (obj->isWidgetType() &&
               ev->type() == QEvent::MouseButtonDblClick &&
               obj->property("gpxkind").isValid()) {
        /* 轨迹面板某行被双击：把视口挪到那条轨迹/收藏（行上装了 gpxkind/gpxidx
         * 两个动态属性，重建面板时随之更新，不会指到已删的条目） */
        locateGpxRow(obj->property("gpxkind").toInt(),
                     obj->property("gpxidx").toInt());
        return true;
    }
    return QMainWindow::eventFilter(obj, ev);
}

/* ---------------- 菜单栏 ---------------- */

/* Qt 5.11 的 addAction(text, shortcut, functor) 重载需要 context 对象，
 * 为避免模板匹配问题统一走显式 QAction：addAction → setShortcut → connect */
static QAction *addAct(QMenu *m, const QString &text, QKeySequence sc,
                       MainWindow *w, std::function<void()> fn)
{
    QAction *act = m->addAction(text);
    act->setShortcut(sc);
    QObject::connect(act, &QAction::triggered, w, [fn](bool) { fn(); });
```

```cpp
/* 把 App::ovl_alpha（百分比 0~100，默认 75）作用到 Qt 这边的浮层上。
 * ★★ 规则：**只淡底板，前景（文字 / 图标）保持清晰**。
 *   ★ 不用 QGraphicsOpacityEffect：它会把图标和文字**一起**淡掉
 *     （浅色底板上的文字糊成灰）。QWidget::setWindowOpacity 也不行 ——

/* 轨迹/收藏面板的样式表：**底板按 pct 淡，文字/图标保持不透明**。
 * pct<=0 ⇒ 前景色 alpha 也归 0（整个面板不可见）。

QString MainWindow::trackPanelStyle(int pct) const

/* ★★ 浮层透明度：**只淡底板，前景（文字 / 图标）保持清晰**。
 *   之前是把 QGraphicsOpacityEffect 挂在浮层容器上 —— 那会把图标和文字
 *   **一起**淡掉：浅色底板上的文字直接糊成灰，越设越看不清
 *   （J 先生 2026-10-25 要求"只淡底板、文字保持清晰"）。
 *   现在改成：
 *     · IconButton（搜索按钮 + 右栏 7 个）：底板/边框的 alpha 乘系数，
 *       图标与文字完全不透明（见 qt_icon_button.hpp）；
 *     · 搜索输入框 / 轨迹面板：用 QSS 的 rgba 背景按系数算 alpha，
 *       前景色保持不透明；
 *     · pct<=0 ⇒ 该浮层整体不画（底板和前景都不画）。
 *   与 C 侧 chrome.c / navdraw.c 的 ak()/afg() 是同一套规则。 */
void MainWindow::applyOverlayAlpha()
{
    const int ps = m_a->ovl_alpha[OVL_SEARCH];
    const int pr = m_a->ovl_alpha[OVL_RCOL];
    const int pt = m_a->ovl_alpha[OVL_TRACK];

    /* --- 搜索浮层：图标按钮 + 输入框 --- */
    if (m_searchBtn) {
        if (auto *ib = dynamic_cast<IconButton *>(m_searchBtn)) ib->setOverlayPct(ps);
    }
    /* 0% ⇒ 整个搜索浮层不显示（否则输入框的文字会孤零零浮在底图上） */
    if (m_searchOverlay) m_searchOverlay->setVisible(ps > 0);
    if (m_search) {
        const double k = ps / 100.0;
        const int bgA = qBound(0, qRound(255 * k), 255);
        const int bdA = qBound(0, qRound(160 * k), 255);
        const int fgA = (ps > 0) ? 255 : 0;
        m_search->setStyleSheet(
            QStringLiteral("QLineEdit{background:rgba(255,255,255,%1);"
                           "border:1px solid rgba(120,130,145,%2);border-radius:4px;"
                           "color:rgba(26,34,51,%3);"
                           "selection-background-color:#3c6edc;selection-color:#ffffff;}")
                .arg(bgA).arg(bdA).arg(fgA));
    }

    /* --- 右栏：全部 IconButton --- */
    if (m_rightOverlay) {
        for (QAbstractButton *b : m_rightOverlay->findChildren<QAbstractButton *>()) {
            if (auto *ib = dynamic_cast<IconButton *>(b)) ib->setOverlayPct(pr);
        }
    }

    /* --- 轨迹 / 收藏面板 --- */
    if (m_trackPanel) {
        m_trackPanel->setStyleSheet(trackPanelStyle(pt));
        m_trackPanel->setVisible(m_trackPanelOpen && pt > 0);
    }
}

         * （applyOverlayAlpha 会按 m_a->ovl_alpha[OVL_TRACK] 设好）。 */
        /* ★ 定宽而不是最小宽：layoutOverlays 用「右栏 x - 面宽 - 6」定位，
           宽度一飘面板就跑到屏幕左边去（实测：按钮行 + wordWrap 提示的
           sizeHint 能把面板撑到 800+ px）。340 刚好放得下按钮行。 */
        m_trackPanel->setFixedWidth(340);
        /* 样式表由 trackPanelStyle(pct) 生成（底板按浮层透明度淡、文字不透明），
           这里先用当前设置里的值建一次，applyOverlayAlpha 会再刷新。 */
        m_trackPanel->setStyleSheet(trackPanelStyle(m_a->ovl_alpha[OVL_TRACK]));
        QVBoxLayout *vl = new QVBoxLayout(m_trackPanel);
        vl->setContentsMargins(8, 8, 8, 8);
        vl->setSpacing(6);
        QLabel *cap = new QLabel(QStringLiteral("轨迹 / 收藏"), m_trackPanel);
        QFont f = cap->font(); f.setBold(true); cap->setFont(f);
        vl->addWidget(cap);

        QScrollArea *sa = new QScrollArea(m_trackPanel);
        sa->setWidgetResizable(true);
        sa->setFrameShape(QFrame::NoFrame);
        sa->setMaximumHeight(360);
        sa->setHorizontalScrollBarPolicy(Qt::ScrollBarAlwaysOff);
        /* ★ 滚动区的 viewport 默认会用调色板画**不透明**底色 ⇒ 面板底板
         *   淡下去之后这一块还是实心的 ⇒ 强制透明。 */
        sa->viewport()->setAttribute(Qt::WA_TranslucentBackground, true);
        m_trackRows = new QWidget(sa);
        m_trackRows->setAttribute(Qt::WA_TranslucentBackground, true);
        QVBoxLayout *rl = new QVBoxLayout(m_trackRows);
        rl->setContentsMargins(2, 2, 2, 2);
        rl->setSpacing(2);
        sa->setWidget(m_trackRows);
        vl->addWidget(sa, 1);

        QHBoxLayout *hb = new QHBoxLayout();
        QPushButton *bimp = new QPushButton(QStringLiteral("导入 GPX…"), m_trackPanel);
        QPushButton *bexp = new QPushButton(QStringLiteral("导出全部…"), m_trackPanel);
        QPushButton *bfav = new QPushButton(QStringLiteral("收藏中心点"), m_trackPanel);
        hb->addWidget(bimp); hb->addWidget(bexp);
        hb->addWidget(bfav);
        hb->addStretch(1);
        vl->addLayout(hb);
        connect(bimp, &QPushButton::clicked, this, [this]() { importGpx(); });
        connect(bexp, &QPushButton::clicked, this, [this]() { exportGpx(); });
        connect(bfav, &QPushButton::clicked, this, [this]() { favCenter(); });
        m_trackPanel->hide();
    }
    /* ★ 用 m_trackPanelOpen 记"逻辑上开没开"，而不是问 isVisible()：
     *   浮层透明度设 0% 时面板**不真的显示**（底板和前景都不画），
     *   若拿 isVisible() 当状态，0% 时再点一次会以为"没开"又去开一次，
     *   开关就乱了。 */
    bool show = !m_trackPanelOpen;
    if (show) refreshTrackPanel();
    m_trackPanelOpen = show;
    m_trackPanel->setVisible(show && m_a->ovl_alpha[OVL_TRACK] > 0);
    /* ★★ 同步按钮勾选态必须**堵信号**：m_trackBtn 是 checkable，且
     *   toggled → toggleTrackPanel（见 buildRightCol）。setChecked 会发 toggled
     *   ⇒ 又调一次 toggleTrackPanel ⇒ 里面再 setChecked（状态这次真变了）⇒
     *   再发 toggled …… 无限递归，每次递归都 refreshTrackPanel 建/删一批控件，
     *   几百层后栈耗尽 ⇒ 在 RtlAllocateHeap 里 SIGSEGV。
     *   （实测：面板第一条 UI 断言就跑成死循环，gdb 里栈深几千层。）
     *   同类写法在整个 Qt 里都成立：setChecked/setValue/setCurrentIndex 前先
     *   QSignalBlocker，除非你就是想递归。 */
    if (m_trackBtn) {
        QSignalBlocker blk(m_trackBtn);
        m_trackBtn->setChecked(show);
    }
    applyOverlayAlpha();   /* 面板刚建好：按浮层透明度刷新底板 */
    layoutOverlays();   /* 面板贴到右栏左边 */
}

void MainWindow::refreshTrackPanel()
{
    if (!m_trackRows) return;
    QVBoxLayout *rl = qobject_cast<QVBoxLayout *>(m_trackRows->layout());
    if (!rl) return;
    /* 清空旧行：行是 QWidget，删它就连它的子布局/子控件一起删 */
    {
        QLayoutItem *child;
        while ((child = rl->takeAt(0)) != nullptr) {
            if (child->widget()) delete child->widget();
            delete child;
        }
    }
    const GpxStore *g = &m_a->gpx;
    auto add_row = [&](int kind, int idx, const QString &text,
                       const QString &tip, const QColor *swatch) {
        QWidget *row = new QWidget(m_trackRows);
        row->setObjectName(QStringLiteral("trkrow"));
        row->setProperty("gpxkind", kind);
        row->setProperty("gpxidx", idx);
        row->setToolTip(tip);
        QHBoxLayout *hl = new QHBoxLayout(row);
        hl->setContentsMargins(4, 2, 4, 2);
        hl->setSpacing(6);
        if (swatch) {
            QLabel *sw = new QLabel(row);
            sw->setFixedSize(12, 12);
            sw->setStyleSheet(QStringLiteral("background:rgb(%1,%2,%3);"
                                             "border:1px solid rgba(0,0,0,110);"
                                             "border-radius:2px;")
                                  .arg(swatch->red()).arg(swatch->green())
                                  .arg(swatch->blue()));
            hl->addWidget(sw);
        }
        QLabel *lb = new QLabel(text, row);
        lb->setToolTip(tip);
        hl->addWidget(lb, 1);
        /* 轨迹行（kind==0）多一个"贴合"按钮：把这条轨迹吸附到道路网（GPX 贴合路线） */
        if (kind == 0) {
            QPushButton *snap = new QPushButton(QString::fromUtf8("贴合"), row);
            snap->setFixedWidth(40);
            snap->setToolTip(QString::fromUtf8("把这条轨迹吸附到道路网（贴合路线）"));
            QObject::connect(snap, &QPushButton::clicked, this, [this, idx]() {
                int rc = app_gpx_snap(m_a, idx);
                if (rc == 0) refreshTrackPanel();   /* 让面板状态（如提示）刷新 */
            });
            hl->addWidget(snap);
        }
        QPushButton *del = new QPushButton(QString::fromUtf8("×"), row);
        del->setFixedWidth(24);
        del->setToolTip(QString::fromUtf8("删除这一条"));
        QObject::connect(del, &QPushButton::clicked, this, [this, kind, idx]() {
            if (kind == 0) gpxDelTrack(idx); else gpxDelFav(idx);
        });
        hl->addWidget(del);
        rl->addWidget(row);
        /* 双击定位：行/色块/名字三个都装过滤器（子控件忽略鼠标事件时会向上
         * 传播到行，但显式装上更稳，不依赖传播规则） */
        row->installEventFilter(this);
        lb->installEventFilter(this);
    };
    for (int i = 0; i < g->n_trk; i++) {
        const GpxTrack *t = &g->trk[i];
        QColor c(t->r, t->g, t->b);
        add_row(0, i,
                QStringLiteral("%1  (%2 点)")
                    .arg(QString::fromUtf8(t->name[0] ? t->name : "(未命名轨迹)"))
                    .arg(t->n),
                QString::fromUtf8("双击定位到这条轨迹的起点"), &c);
    }
    for (int i = 0; i < g->n_wpt; i++) {
        const GpxWpt *w = &g->wpt[i];
        add_row(1, i,
                QString::fromUtf8("★ ") +
                    QString::fromUtf8(w->name[0] ? w->name : "(未命名)"),
                QString::fromUtf8("双击定位到这个收藏点"), nullptr);
    }
    if (g->n_trk == 0 && g->n_wpt == 0) {
        QLabel *hint = new QLabel(
            QString::fromUtf8("（还没有轨迹：点「导入 GPX…」选一个 .gpx 文件，"
                              "或用 Ctrl+D 收藏视口中心）"),
            m_trackRows);
        hint->setObjectName(QStringLiteral("trkempty"));
        hint->setWordWrap(true);
        rl->addWidget(hint);
    }
    rl->addStretch(1);
}

{

        tot->setObjectName(QStringLiteral("viatotal"));
        rl->addWidget(tot);
    }
    rl->addStretch(1);
}

/* 无图区弹窗 + 预选下载的无头验收（--shot-nomap）。
 *
 * 为什么要它：本轮把"无图区提示"从一句"没有数据"改成"反查国家/省/市/区 +
 * 一键下载该地区"，其中最容易静默失效的两处是
 *   ① 反查结果没传到弹窗（两处各读一份数据，天然会漂移）；
 *   ② DownloadDialog::selectByLeaf 找不到叶子（拼音/路径对不上就静默不选）。
 * 两者都不会报错、界面照样打开，只是"按钮点下去停在树根，用户还得自己翻"。
 * 所以这里把它们做成断言：失败返回非 0，进 regress 就能拦住。
 */
int MainWindow::runNoMapPromptForShot()
{
    int fails = 0;

    /* ★ 必须先主动刷一次：--shot 不跑主循环，paint_frame 没被调用过，
     *   cov_place 还是全零（实测就这么踩到：反查全 "—"，看着像反查坏了，
     *   其实是"还没算"）。这里强制重算，把"没算"和"算错"区分开。 */
    app_refresh_coverage(m_a);
    const CovPlace &pl = m_a->cov_place;

    /* 有图区跑这个自检没有意义（本来就不该弹窗，反查也按设计留空）。
     * 明确区分"没到无图区"与"反查坏了"——否则在有图的位置跑一次就一片假 FAIL。 */
    if (m_a->cov_state != COV_NONE && m_a->cov_state != COV_BBOX_ONLY) {
        printf("nomap_reverse  跳过（当前位置有地图数据，cov_state=%d）\n",
               m_a->cov_state);
        return 0;
    }

    printf("nomap_reverse  国家=%s 省=%s%s 市=%s 区=%s 距离=%.0fkm 建议=%s\n",
           pl.country[0] ? pl.country : "—",
           pl.prov[0] ? pl.prov : "—", pl.prov_guessed ? "(推断)" : "",
           pl.city[0] ? pl.city : "—",
           pl.district[0] ? pl.district : "—",
           pl.nearest_km,
           pl.dl_label[0] ? pl.dl_label : "—");

    /* ① 反查必须给出"该下哪一块"，否则"一键下载"无从谈起 */
    if (!pl.dl_name[0] || !pl.dl_label[0]) {
        printf("ASSERT-FAIL    反查没给出建议下载项（dl_name/dl_label 为空）\n");
        fails++;
    }

    /* ② 弹窗里必须出现反查到的地名（证明弹窗读的是同一份 CovPlace） */
    const QString prompt = nomapPromptTextForTest();
    if (pl.prov[0] && !prompt.contains(QString::fromUtf8(pl.prov))) {
        printf("ASSERT-FAIL    弹窗里没出现反查到的省「%s」：%s\n",
               pl.prov, prompt.toUtf8().constData());
        fails++;
    }

    /* ③ selectByLeaf 必须真的命中并选中（这是"一键下载"的关键一步） */
    if (pl.dl_name[0]) {
        showDownloadDialog();
        const QString leaf = QString::fromLatin1(pl.dl_name);
        if (!m_dlDlg || !m_dlDlg->selectByLeaf(leaf)) {
            printf("ASSERT-FAIL    下载对话框里找不到地区叶子「%s」\n",
                   pl.dl_name);
            fails++;
        } else {
            /* 选中之后，"将下载的省名"应当等于反查给出的叶子名 —— 这一条把
             * "找到了但选错行"也拦住（同名叶子在别的国家是可能的）。 */
            const QString got = m_dlDlg->currentLeafForTest();
            if (got != leaf) {
                printf("ASSERT-FAIL    预选到了错的行：期望「%s」实得「%s」\n",
                       pl.dl_name, got.toUtf8().constData());
                fails++;
            } else {
                printf("nomap_select   预选命中 %s（GitHub 路径已就绪）\n", pl.dl_name);
            }
        }
    }
    return fails;
}

void MainWindow::locateGpxRow(int kind, int idx)
{
    const GpxStore *g = &m_a->gpx;
    double la, lo;
    if (kind == 0) {
        if (idx < 0 || idx >= g->n_trk || g->trk[idx].n == 0) return;
        la = g->trk[idx].lat_e7[0] / 1e7;
        lo = g->trk[idx].lon_e7[0] / 1e7;
    } else {
        if (idx < 0 || idx >= g->n_wpt) return;
        la = g->wpt[idx].lat; lo = g->wpt[idx].lon;
    }
    m_a->view.lat = la; m_a->view.lon = lo;
    m_a->need_redraw = 1;
}

void MainWindow::importGpx()
{
    QString path = QFileDialog::getOpenFileName(
        this, QStringLiteral("导入 GPX 文件"), QString(),
        QStringLiteral("GPX 轨迹 (*.gpx);;所有文件 (*)"));
    if (path.isEmpty()) return;
    int n = app_gpx_import(m_a, path.toUtf8().constData());
    if (n < 0)
        snprintf(m_a->status, sizeof(m_a->status),
                 "GPX 导入失败：%s（解析不到 trk/rte/wpt？）",
                 path.toUtf8().constData());
    else
        snprintf(m_a->status, sizeof(m_a->status),
                 "已导入 %d 条轨迹 / 收藏若干（来自 %s）", n,
                 path.toUtf8().constData());
    refreshTrackPanel();
    if (m_trackPanel && m_trackPanel->isVisible()) layoutOverlays();
    m_a->need_redraw = 1;
}

void MainWindow::exportGpx()
{
    QString path = QFileDialog::getSaveFileName(
        this, QStringLiteral("导出全部为 GPX"), QStringLiteral("navimap-tracks.gpx"),
```

```cpp
 * ★ 为什么不用 QToolButton::setIcon()：图标尺寸由 style 决定，会被画到一角。

#ifndef NAVIMAP_QT_ICON_BUTTON_HPP
#define NAVIMAP_QT_ICON_BUTTON_HPP

#include <QToolButton>
#include <QPainter>
#include <QPixmap>

#include "qt_icons.h"

class IconButton : public QToolButton {
public:
    IconButton(Qt::IconKind kind, const QString &tip, QWidget *parent = nullptr)
        : QToolButton(parent), m_kind(kind)
    {
        setToolTip(tip);
        setToolButtonStyle(Qt::ToolButtonIconOnly);
        setAutoRaise(false);
        setFocusPolicy(Qt::NoFocus);
        setCursor(Qt::PointingHandCursor);
        setAttribute(Qt::WA_Hover, true);
        setFixedSize(kSize, kSize);
    }

    static const int kSize = 36;
    static const int kIcon = 20;

    void setOverlayPct(int pct)
    {
        if (m_ovlPct == pct) return;
        m_ovlPct = pct;
        update();
    }
    int overlayPct() const { return m_ovlPct; }

protected:
    void paintEvent(QPaintEvent *) override
    {
        if (m_ovlPct <= 0) return;

        QPainter p(this);
        p.setRenderHint(QPainter::Antialiasing, true);

        QColor bg(255, 255, 255, 225);
        QColor bd(120, 130, 145, 160);
        if (isChecked()) {
            bg = QColor(214, 228, 250, 235);
            bd = QColor(60, 110, 200, 230);
        }
        if (isDown()) {
            bg = QColor(205, 220, 245, 235);
        } else if (underMouse()) {
            bg = QColor(255, 255, 255, 250);
            bd = QColor(60, 110, 200, 220);
        }
        /* ★ 只有底板/边框按浮层透明度淡；图标与文字保持完全不透明。 */
        const double k = m_ovlPct / 100.0;
        bg.setAlpha(qBound(0, qRound(bg.alpha() * k), 255));
        bd.setAlpha(qBound(0, qRound(bd.alpha() * k), 255));

        const qreal r = 6.0;
        QRectF box = QRectF(rect()).adjusted(0.5, 0.5, -0.5, -0.5);
        p.setPen(QPen(bd, 1.0));
        p.setBrush(bg);
        p.drawRoundedRect(box, r, r);

        const bool withText = !text().isEmpty() &&
                              toolButtonStyle() == Qt::ToolButtonTextBesideIcon;
        if (withText) {
            QRect tr = rect().adjusted(8, 0, -8, 0);
            QFontMetrics fm(font());
            int tw = fm.horizontalAdvance(text());
            int ih = kIcon;
            int gap = 6;
            int total = ih + gap + tw;
            int x = tr.left() + (tr.width() - total) / 2;
            p.save();
            p.translate(x, tr.center().y() - ih / 2.0);
            qt_draw_icon(p, m_kind, ih);
            p.restore();
            p.setPen(QColor(0x2c, 0x34, 0x40));
            p.drawText(QRect(x + ih + gap, tr.top(), tw + 2, tr.height()),
                       Qt::AlignVCenter | Qt::AlignLeft, text());
        } else {
            p.save();
            p.translate(rect().center().x() - kIcon / 2.0,
                        rect().center().y() - kIcon / 2.0);
            qt_draw_icon(p, m_kind, kIcon);
            p.restore();
        }
    }

private:

    int m_ovlPct = 100;
```

```cpp
        out.setDevicePixelRatio(kScale);

    }

}
```

```cpp
 * 问题：Qt 控件的文字由 Qt 自己绘制，走 Qt 的字体系统；地图上的文字由 C 侧

 * 解法：把 C 侧自带的字体注册进 Qt 的字体数据库。
 */
#include "qt_font.h"

#include <QApplication>
#include <QFont>
#include <QFontDatabase>
#include <QFontInfo>
#include <QFontMetrics>
#include <QString>
#include <QStringList>

#include <cstdio>

extern "C" {
#include "render/font.h"
#include "utils/plat.h"

/* 这个字体**文件**里有没有"中"字形？直接查 cmap，不依赖 Qt 的度量。 */
static bool file_has_cjk(const char *path)
{
    Font *f = font_open(path, 14);
    if (!f) return false;
    int face = -1, gi = -1, w = 0, h = 0, nz = 0;
    bool ok = false;
    if (font_probe_glyph(f, 0x4E2D /* 中 */, &face, &gi, &w, &h, &nz)) {
        ok = (gi != 0) && (nz > 0);
    }
    font_close(f);
    return ok;
}

QString qt_setup_fonts(int pointSize)
{
    size_t n = 0;
    const char *const *cands = nm_font_candidates(&n);

    QStringList cjkFamilies;
    QStringList allFamilies;
    for (size_t i = 0; i < n; i++) {
        if (!cands[i]) continue;
        int id = QFontDatabase::addApplicationFont(QString::fromUtf8(cands[i]));
        if (id < 0) continue;
        QStringList fams = QFontDatabase::applicationFontFamilies(id);
        bool cjk = file_has_cjk(cands[i]);
        for (const QString &fam : fams) {
            if (!allFamilies.contains(fam)) allFamilies.append(fam);
            if (cjk && !cjkFamilies.contains(fam)) cjkFamilies.append(fam);
            fprintf(stderr, "[qt-font]   文件 %-30s → 族 %-24s 含中文: %s\n",
                    cands[i], fam.toUtf8().constData(), cjk ? "是" : "否");
        }
    }

    const char *kSysCjk[] = {
        "Microsoft YaHei", "SimSun", "SimHei", "KaiTi", "FangSong",
        "Noto Sans CJK SC", "Noto Sans CJK TC", "Source Han Sans SC",
        "WenQuanYi Micro Hei", "Droid Sans Fallback", "PingFang SC",
    };
    QStringList sysFams = QFontDatabase().families();
    for (const char *name : kSysCjk) {
        QString fam = QString::fromUtf8(name);
        if (!sysFams.contains(fam)) continue;
        if (!allFamilies.contains(fam)) allFamilies.append(fam);
        if (!cjkFamilies.contains(fam)) cjkFamilies.append(fam);
    }

    if (cjkFamilies.isEmpty()) {
        fprintf(stderr,
                "[qt-font] 警告：没有可用中文字体，Qt 控件的中文会显示为方框"
                "（地图上的文字不受影响：那是 C 侧 stb_truetype 画的）\n");
        return QString();
    }

    QStringList chain = cjkFamilies;
    for (const QString &fam : allFamilies) {
        if (!chain.contains(fam)) chain.append(fam);
    }
    QFont app_font = QApplication::font();
#if QT_VERSION >= QT_VERSION_CHECK(6, 0, 0)
    app_font.setFamilies(chain);
#else
    app_font.setFamily(chain.first());
#endif
    app_font.setPointSize(pointSize > 0 ? pointSize : app_font.pointSize());
    QApplication::setFont(app_font);

    fprintf(stderr, "[qt-font] 中文字体: %s（候选 %d 个文件，可用中文字族 %d）\n",
            cjkFamilies.first().toUtf8().constData(), (int)n, (int)cjkFamilies.size());
    return cjkFamilies.first();
}
```

```cpp
/* 按叶子名预选：递归找 path 最后一段 == leaf 的节点。 */
bool DownloadDialog::selectByLeaf(const QString &leaf)
{
    if (leaf.isEmpty() || !m_tree) return false;

    std::function<QTreeWidgetItem *(QTreeWidgetItem *)> walk =
        [&](QTreeWidgetItem *parent) -> QTreeWidgetItem * {
        for (int i = 0; i < parent->childCount(); i++) {
            QTreeWidgetItem *it = parent->child(i);
            QString path = it->data(0, ROLE_PATH).toString();
            if (!path.isEmpty() && path.section('/', -1) == leaf) return it;
            if (QTreeWidgetItem *sub = walk(it)) return sub;
        }
        return nullptr;
    };

    QTreeWidgetItem *hit = walk(m_tree->invisibleRootItem());
    if (!hit) return false;

    for (QTreeWidgetItem *p = hit->parent(); p; p = p->parent()) p->setExpanded(true);
    m_tree->setCurrentItem(hit);
    m_tree->scrollToItem(hit);
    return true;
}
```

```cpp
void DownloadDialog::fillTree(QTreeWidgetItem *parent, const QVector<GeoRegion> &rs)
{
    for (const GeoRegion &r : rs) {
        auto *it = new QTreeWidgetItem(parent);
        /* 仅搭结构 + 存 path/name；文本与颜色由 refreshStatus() 统一计算，
         * 这样刷新状态不必重建整棵树（保留展开/选中状态）。 */
        it->setData(0, ROLE_PATH, QVariant(r.path));   /* 枝的 path 为空串 */
        it->setData(0, ROLE_NAME, QVariant(r.name));
        it->setChildIndicatorPolicy(r.kids.isEmpty()
                                    ? QTreeWidgetItem::DontShowIndicator
                                    : QTreeWidgetItem::ShowIndicator);
        if (!r.kids.isEmpty()) fillTree(it, r.kids);
    }
}

bool DownloadDialog::regionDownloaded(const QString &path) const
{
    if (path.isEmpty()) return false;              /* 枝不计已下载 */
    QString nm = path.section('/', -1);            /* asia/china/gansu → gansu */
    if (QDir(m_repo + "/products/graph/" + nm).exists()) return true;
    if (QFile::exists(m_sources + "/" + nm + "-latest.osm.pbf")) return true;
    return false;
}

void DownloadDialog::refreshStatus()
{
    QTreeWidgetItem *root = m_tree->invisibleRootItem();
    for (int i = 0; i < root->childCount(); i++)
        refreshItem(root->child(i));
}

QPair<int,int> DownloadDialog::refreshItem(QTreeWidgetItem *it)
{
    QString path = it->data(0, ROLE_PATH).toString();
    QString base = it->data(0, ROLE_NAME).toString();

    if (it->childCount() == 0) {                  /* 叶子：直接判定 */
        bool dl = regionDownloaded(path);
        it->setText(0, base + (dl ? QString::fromUtf8("  ✓已下载")
                                  : QString::fromUtf8("  ·未下载")));
        it->setForeground(0, QBrush(dl ? QColor(0, 128, 0) : QColor(120, 120, 120)));
        return qMakePair(1, dl ? 1 : 0);
    }

    int total = 0, d = 0;                          /* 枝：汇总子节点 */
    for (int i = 0; i < it->childCount(); i++) {
        QPair<int,int> c = refreshItem(it->child(i));
        total += c.first; d += c.second;
    }
    it->setText(0, base + QString::fromUtf8("  (%1/%2)").arg(d).arg(total));
    it->setForeground(0, QBrush(Qt::black));
    return qMakePair(total, d);
}

bool DownloadDialog::isLeafDownloaded(const QString &leaf) const
{
    if (leaf.isEmpty() || !m_tree) return false;

        [&](QTreeWidgetItem *parent) -> QString {

void DownloadDialog::startDownload()
{
    QString path = currentPath();
    if (path.isEmpty()) return;

    m_dlName = currentName();
    m_target = m_sources + "/" + m_dlName + "-latest.osm.pbf";

    /* 先查本地：pbf 已存在且非空 → 比对远端是否有更新，再决定是否下载。
     * 与 SRTM 的"缺失才下载"一致；存在时不再盲目覆盖，有更新才询问用户。 */
    if (QFile::exists(m_target) && QFileInfo(m_target).size() > 0) {
        m_dl->setEnabled(false); m_copy->setEnabled(false);
        m_log->append(QString::fromUtf8("本地已存在 %1。正在比对远端是否有更新…").arg(m_target));
        QNetworkRequest req(currentUrl());
#if QT_VERSION >= QT_VERSION_CHECK(5, 15, 0)
        req.setAttribute(QNetworkRequest::RedirectPolicyAttribute,
                         QNetworkRequest::NoLessSafeRedirectPolicy);
#endif
        QNetworkReply *r = m_nam->head(req);
        connect(r, &QNetworkReply::finished, this, [this, r]() { onHeadFinished(r); });
        return;
    }

    beginDownload();
}

void DownloadDialog::beginDownload()
{
    m_log->append(QString::fromUtf8("开始下载：%1\n  → %2").arg(currentUrl(), m_target));

    m_dl->setEnabled(false); m_copy->setEnabled(false);
    m_prog->setValue(0);

    QDir().mkpath(m_sources);
    m_file = new QFile(m_target, this);
    if (!m_file->open(QIODevice::WriteOnly | QIODevice::Truncate)) {
        m_log->append(QString::fromUtf8("无法创建目标文件：%1").arg(m_target));
        m_dl->setEnabled(true); m_copy->setEnabled(true);
        return;
    }

    QNetworkRequest req(currentUrl());   /* Qt6 默认跟随重定向，无需额外属性 */
    m_reply = m_nam->get(req);
    connect(m_reply, &QNetworkReply::downloadProgress,
            this, &DownloadDialog::onDownloadProgress);
    connect(m_reply, &QIODevice::readyRead, this, &DownloadDialog::onReadyRead);
    connect(m_reply, &QNetworkReply::finished, this,
            [this]() { onReplyFinished(m_reply); });
}

/* 本地已有 pbf 时，先发 HEAD 比对远端新鲜度：
 *   - 比对失败（无网络/无法访问）→ 稳妥起见跳过下载；
 *   - 远端无更新 → 跳过下载；
 *   - 远端有更新 → 弹窗询问用户是否更新。 */
void DownloadDialog::onHeadFinished(QNetworkReply *r)
{
    r->deleteLater();
    m_dl->setEnabled(true); m_copy->setEnabled(true);

    if (r->error() != QNetworkReply::NoError) {
        m_log->append(QString::fromUtf8("无法比对远端（%1）。为稳妥起见保留本地文件，跳过下载。"
                        "如需强制刷新，请先删除本地文件后重试。").arg(r->errorString()));
        return;
    }

    bool remoteNewer = false;
    QString lm = r->header(QNetworkRequest::LastModifiedHeader).toString();
    if (!lm.isEmpty()) {
        QDateTime remoteMod = QDateTime::fromString(lm, Qt::RFC2822Date);
        if (remoteMod.isValid() && QFileInfo(m_target).lastModified() < remoteMod)
            remoteNewer = true;
    }
    if (!remoteNewer) {
        qint64 remoteSize = r->header(QNetworkRequest::ContentLengthHeader).toLongLong();
        qint64 localSize  = QFileInfo(m_target).size();
        if (remoteSize > 0 && remoteSize != localSize)
            remoteNewer = true;
    }

    if (!remoteNewer) {
        m_log->append(QString::fromUtf8("远端无更新（本地已是最新），跳过下载。"));
        return;
    }

    QMessageBox::StandardButton ret = QMessageBox::question(
        this, QString::fromUtf8("发现更新"),
        QString::fromUtf8("本地已有 %1，远端存在更新版本。是否下载更新？\n（选择\"否\"将保留本地文件。）").arg(m_dlName),
        QMessageBox::Yes | QMessageBox::No, QMessageBox::Yes);
    if (ret == QMessageBox::Yes) {
        m_log->append(QString::fromUtf8("用户选择更新，开始下载…"));
        beginDownload();
    } else {
        m_log->append(QString::fromUtf8("用户选择保留本地文件，跳过下载。"));
    }
}

void DownloadDialog::onReplyFinished(QNetworkReply *r)
{
    if (m_file) { m_file->close(); delete m_file; m_file = nullptr; }

    if (r->error() != QNetworkReply::NoError) {
        m_log->append(QString::fromUtf8("下载失败：%1").arg(r->errorString()));
        m_dl->setEnabled(true); m_copy->setEnabled(true);
        r->deleteLater(); m_reply = nullptr;
        return;
    }
    m_log->append(QString::fromUtf8("下载完成（%1 字节），开始转换…").arg(m_target));
    r->deleteLater(); m_reply = nullptr;

    /* 下载完即触发转换：sync_maps.sh 会扫整个 sources/ 把新 PBF 转成可加载的路网。
     * 异步跑（转换一个省可能几分钟），完成后 downloadFinished 通知主窗口重载。 */
    m_proc = new QProcess(this);
    connect(m_proc, &QProcess::readyReadStandardOutput, this, &DownloadDialog::onConvertOutput);
    connect(m_proc, QOverload<int, QProcess::ExitStatus>::of(&QProcess::finished),
            this, &DownloadDialog::onConvertFinished);
    m_proc->setWorkingDirectory(m_repo);
    m_proc->start(QStringLiteral("bash"),
                 QStringList() << (m_repo + "/scripts/sync_maps.sh"));
    m_log->append(QString::fromUtf8("运行 sync_maps.sh（转换 + 建地名库 + 地标表）…"));
}

void DownloadDialog::onConvertOutput()
{
    if (m_proc) m_log->append(QString::fromLocal8Bit(m_proc->readAllStandardOutput()));
}

void DownloadDialog::onConvertFinished(int code, QProcess::ExitStatus)
{
    if (code == 0) {
        m_log->append(QString::fromUtf8("转换完成 ✓ 地图已就绪。"));
        refreshStatus();                 /* 刚下载的省翻成「✓已下载」 */
        if (m_onFinished) m_onFinished(m_dlName);
        // 生成等高线（如果用户勾选了）
        if (m_contourCb && m_contourCb->isChecked()) {
            runContoursGeneration();
        }
    } else {
        m_log->append(QString::fromUtf8("转换失败（exit %1）。可在终端手动运行 scripts/sync_maps.sh 查看详情。").arg(code));
    }
}

/* 运行等高线生成（若工具可用）*/
void DownloadDialog::runContoursGeneration()
{
    // 省目录路径
    QString provDir = m_repo + "/products/graph/" + m_dlName;
    
    // 用 pbf_info 获取 PBF 的 bbox
    QString pbfPath = m_sources + "/" + m_dlName + "-latest.osm.pbf";
    if (!QFile::exists(pbfPath)) {
        m_log->append(QString::fromUtf8("  [等高线] PBF 文件不存在，跳过生成。"));
        return;
    }
    
    // 检查 pbf_info 工具是否存在（构建产物在 build/ 顶层，历史曾在 build/tools/，两者都探）
    QString pbfInfo = m_repo + "/build/pbf_info.exe";
    if (!QFile::exists(pbfInfo))
        pbfInfo = m_repo + "/build/tools/pbf_info.exe";
    if (!QFile::exists(pbfInfo)) {
        m_log->append(QString::fromUtf8("  [等高线] pbf_info 工具未编译，跳过生成。"));
        return;
    }
    
    QProcess proc;
    proc.setWorkingDirectory(m_repo);
    proc.start(pbfInfo, QStringList() << pbfPath);
    if (!proc.waitForFinished(5000)) {
        m_log->append(QString::fromUtf8("  [等高线] pbf_info 运行超时，跳过生成。"));
        return;
    }
    
    // 解析输出，寻找 "bbox_observed"（由 pbf_info 输出）
    QByteArray out = proc.readAllStandardOutput();
    QList<QByteArray> lines = out.split('\n');
    double lat0 = 0.0, lon0 = 0.0, lat1 = 0.0, lon1 = 0.0;
    bool found = false;
    for (const QByteArray &line : lines) {
        if (line.startsWith("bbox_observed")) {
            QList<QByteArray> parts = line.split(' ');
            if (parts.size() >= 6) {
                lat0 = parts[2].toDouble() / 1e9;
                lon0 = parts[3].toDouble() / 1e9;
                lat1 = parts[4].toDouble() / 1e9;
                lon1 = parts[5].toDouble() / 1e9;
                found = true;
                break;
            }
        }
    }
    if (!found) {
        m_log->append(QString::fromUtf8("  [等高线] 无法从 PBF 提取 bbox，跳过生成。"));
        return;
    }
    m_log->append(QString::fromUtf8("  [等高线] 区域范围：%1,%2 – %3,%4")
                  .arg(lat0, 0, 'f', 4).arg(lon0, 0, 'f', 4)
                  .arg(lat1, 0, 'f', 4).arg(lon1, 0, 'f', 4));
    
    // 首先检查是否已存在该区域的等高线文件（避免重复生成）
    QString contPath = provDir + "/" + m_dlName + "_contours.bin";
    if (!QFile::exists(contPath)) contPath = provDir + "/contours.bin";  // 旧命名回退
    if (QFile::exists(contPath)) {
        m_log->append(QString::fromUtf8("  [等高线] 检测到已存在 %1，跳过生成。").arg(contPath));
        return;
    }
    
    // 创建 SRTM 缓存目录（在项目根下）
    QString srtmDir = m_repo + "/srtm_cache";
    if (!QDir().mkpath(srtmDir)) {
        m_log->append(QString::fromUtf8("  [等高线] 无法创建 SRTM 缓存目录，跳过生成。"));
        return;
    }
    
    // 检查 bbox 覆盖的 SRTM 瓦片，判断是否全部已存在
    int tlat_lo = (int)std::floor(lat0), tlat_hi = (int)std::floor(lat1);
    int tlon_lo = (int)std::floor(lon0), tlon_hi = (int)std::floor(lon1);
    int totalTiles = 0, existingTiles = 0;
    for (int tlat = tlat_lo; tlat <= tlat_hi; tlat++) {
        for (int tlon = tlon_lo; tlon <= tlon_hi; tlon++) {
            totalTiles++;
            QString ns = (tlat >= 0) ? "N" : "S";
            QString ew = (tlon >= 0) ? "E" : "W";
            QString tileName = QString("%1%2%3%4.hgt")
                                  .arg(ns).arg(abs(tlat), 2, 10, QChar('0'))
                                  .arg(ew).arg(abs(tlon), 3, 10, QChar('0'));
            QString tilePath = srtmDir + "/" + tileName;
            if (QFile::exists(tilePath) && QFileInfo(tilePath).size() > 1000) {
                existingTiles++;
            }
        }
    }
    
    // 瓦片去重：仅当 existingTiles < totalTiles 才在下方追加 --download（见后文）

    
    QString contourExe = m_repo + "/build/gen_contours.exe";
    if (!QFile::exists(contourExe)) {
        m_log->append(QString::fromUtf8("  [等高线] gen_contours 工具未编译，跳过生成。"));
        return;
    }
    
    if (existingTiles == totalTiles) {
        // 所有需要的 SRTM 瓦片都已存在，跳过下载，只生成等高线
        m_log->append(QString::fromUtf8("  [等高线] 区域内 %1 张 SRTM 瓦片已全部存在，仅生成等高线。").arg(totalTiles));
        // 不传 --download 参数，直接使用已有的瓦片生成
    } else if (existingTiles > 0) {
        m_log->append(QString::fromUtf8("  [等高线] 区域内 %1/%2 张 SRTM 瓦片已存在，自动下载缺失的瓦片。").arg(existingTiles).arg(totalTiles));
    }
    
    // 构造命令：等高线文件按区域命名（<name>_contours.bin 等）
    QString bboxStr = QString("%1,%2,%3,%4").arg(lat0).arg(lon0).arg(lat1).arg(lon1);
    QStringList args;
    args << "--out-dir=" + provDir
         << "--hgt-dir=" + srtmDir
         << "--prefix=" + m_dlName
         << "--bbox=" + bboxStr
         << "--interval=20"
         << "--index=100";

    // 只有当有缺失瓦片时才添加 --download 参数
    if (existingTiles < totalTiles) {
        args << "--download";  // 自动下载缺失瓦片
    }
    
    QProcess genProc;
    genProc.setWorkingDirectory(m_repo);
    genProc.start(contourExe, args);
    connect(&genProc, &QProcess::readyReadStandardOutput,
            [this, &genProc]() {
                m_log->append(QString::fromUtf8("  [等高线] %1").arg(
                    QString::fromLocal8Bit(genProc.readAllStandardOutput()).trimmed()));
            });
    connect(&genProc, &QProcess::readyReadStandardError,
            [this, &genProc]() {
                m_log->append(QString::fromUtf8("  [等高线]⚠ %1").arg(
                    QString::fromLocal8Bit(genProc.readAllStandardError()).trimmed()));
            });
    if (!genProc.waitForFinished(120000)) {  // 2 分钟超时
        m_log->append(QString::fromUtf8("  [等高线] 生成超时（2 分钟），已强制停止。"));
        genProc.kill();
        return;
    }
    int rc = genProc.exitCode();
    if (rc == 0) {
        m_log->append(QString::fromUtf8("  [等高线] 生成完成 ✓ 地图目录已包含等高线数据。"));
    } else {
        m_log->append(QString::fromUtf8("  [等高线] 生成失败（exit %1）。可在命令行手动运行：%2 %3")
                      .arg(rc).arg(QFileInfo(contourExe).fileName()).arg(args.join(" ")));
    }
}
```

> 注：`DownloadDialog` 刻意不用 `Q_OBJECT`/`moc`，以 `std::function` 回调（如 `setOnFinished` 注册的 `m_onFinished`）代替信号槽，因此上述方法体均为普通成员函数，可直接逐字编译。

## 四、与其他功能之间的联系

- **上游（消费）**：第 8 课 `app_render_to_buf`（C 核心一行不动）、`mv_*` 投影/`mv_zoom_at`/`mv_clamp_zoom`/`mv_unproject`；第 11 课 `app_nav_poll`/`app_nav_sim_tick`/`app_nav_click`/`app_nav_clear`/`app_nav_fit`/`app_nav_sim_*`/`nav_voice_frame`（V 键经 `handleKey` 置 `app.voice_on`，接第 11 课 `voice_wire`）；第 10/11 课 `maneuver`/`RouteResult`/`Maneuver`（用于 `refreshSteps` 指令条）；`app_search_query`/`SearchHit`（搜索框与结果列表）。
- **边界原则**：Qt 前端**不链 SDL**（`m_px` 自 `new uint32_t[]`，C 侧零 SDL）；叠加层只用 `QPainter`。`qt_ui=1` 时第 8 课 `paint_frame` 跳过 C 侧 chrome/搜索框/面板，由 Qt 真控件承担。
- **字体两系统**：地图文字走 C 侧 `stb_truetype`（`render/font.c`），控件文字走 Qt；`qt_font.cpp` 把 C 侧 CJK 字体注册进 Qt，避免控件中文变豆腐块。
- **下游 · 第 13 课**：被 `regress.sh` 的 `--shot-offscreen` 像素审计与 `offscreen_shot_main` 验收；`core_no_sdl` 锁死"Qt 不链 SDL"（`tools/core_no_sdl.c`）。

## 五、演示、练习与验收

- **演示**：`./build_rel/navmap_qt --graph=products/graph/beijing`（GUI 里缩放/平移/搜索/模拟导航/下载，肉眼确认交互）；`./build_rel/navmap_qt --shot=out.png`（无人值守出一张含 chrome 的截图）；`./build_rel/navmap_qt --ui-test`（无头 UI 自检，断言"搜索按钮→点击→输入框出现→Esc 收起"这条链）。
- **练习**：

  - 在 `qt_icons.cpp` 里加一个自绘矢量图标（如 `drawStar`），在 `IconKind` 中登记并在右栏加一个 `IconButton`，确认不依赖任何字体符号。

- **验收**：能说清
  1. Qt 前端改了什么、C 核心为什么完全没动（`MapCanvas::renderNow` → `app_render_to_buf` → 包成 `QImage`）；

  4. 字体符号不可用 ⇒ 图标必须自绘矢量路径（`qt_icons.cpp` 的 `draw*` 函数 + `qt_draw_icon`）；
  5. `qt_font.cpp` 把 C 侧 CJK 字体注册进 Qt 的原因。
