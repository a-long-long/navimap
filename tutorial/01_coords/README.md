# 第 1 课 · 坐标系

> 📖 配套读源码讲义：[`docs/teaching/01_coords.md`](../../docs/teaching/01_coords.md)（读源码式讲解，讲清楚“为什么这么写”；与本科小程序同号对应）


**累加内容**：在"最小框架"的像素缓冲上，加入第一层概念——坐标系。
把"地球坐标 ↔ 屏幕像素"这条主线的两端先打通：经纬度怎么量化、怎么测距、怎么画到画布。

**运行**：
```bash
gcc -std=c11 -O2 -o tut main.c && ./tut
```

**你会看到**：米白底上每隔 10° 一条经纬网，北京/上海/广州三个蓝方块，以及北京到上海的红线；
stdout 打印量化往返误差（≈1e-7 度）和两段 haversine 距离。

**三个关键不变量（项目里也是这样）**：
1. **内部坐标永远是 WGS84、量化成 1e-7 度 int32**（`lat_to_i32`）。坐标系只影响"显示读数"，
   不重投影底图——这是整个工程坐标系教学的锚点。
2. **测距一律 haversine**；Web Mercator 只用于显示，拿来测距会随纬度失真。
3. **geo→pixel 是线性视框映射的雏形**；真正的 `mv_project`（第 6 课）在此基础上引入墨卡托
   和"投影缓存惰性失效"。

**生产最终形态**（对照）：
- `src/utils/geo.c`：`nm_lat_to_i32` / `nm_i32_to_deg`（量化）、`nm_haversine_m`（测距）、
  `nm_mercator` / `nm_mercator_y_fast`（**快版故意不逐位等于精确版**，换 5~6× 速度）。
- `src/utils/datum.c`：`datum_wgs84_to` / `datum_gk_forward`（高斯方里格读数）。

**练习**：把视框 `LON0/LAT0` 改成你所在城市的范围，重画一张本地经纬网。
